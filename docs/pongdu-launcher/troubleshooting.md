# 문제 해결

## "이미 실행 중입니다"

퐁듀는 중복 실행을 막습니다. 작업 관리자에서 `PongDu.exe`가 이미 떠 있는지 확인하세요. 창이 안 보이면 작업 표시줄이나 시스템 트레이에 숨어있을 수 있습니다.

## "시즌 참가 목록에 없는 채널입니다"

로그인한 계정의 채널이 이번 시즌 화이트리스트에 없습니다. 로그인 자체는 정상이므로 **다른 계정으로 로그인** 버튼으로 다른 계정을 시도할 수 있습니다.

화이트리스트 검사는 런처가 아니라 인증 서버가 토큰 발급/갱신과 함께 수행합니다. 네트워크 문제로 조회 자체가 실패한 경우에도 안전을 위해 차단 처리되므로, 인터넷 연결을 확인하고 재시도하세요.

## 자동 로그인이 안 됨

저장된 Refresh Token이 만료(30일)됐거나 무효화된 경우입니다. 로그인 버튼이 다시 나타나면 그냥 한 번 더 로그인하면 됩니다.

## 연동 준비 확인이 안 넘어감

**연동 시작** 버튼은 4가지가 모두 초록색이어야 활성화됩니다.

| 항목 | 확인할 것 |
| ---- | --------- |
| 치지직 로그인 완료 | 로그인 + 화이트리스트 통과 |
| 생방송 중 | 방송이 실제로 켜져 있는지 |
| 인게임 접속 완료 | 서버에 실제로 접속했는지 (로비/로딩 화면이 아닌 상태) |
| 서버 리워드 설정 확인됨 | 아래 항목 참고 |

## "서버 리워드 설정 확인" 이 안 켜짐

이 항목은 **인게임 접속이 확인된 뒤에만** 판정합니다. 접속 전에는 "인게임 접속 후 확인됩니다"로 표시되는 게 정상입니다.

접속했는데도 안 켜진다면:

1. **Zomboid 폴더가 틀렸을 가능성** — 게이트 화면의 **폴더 선택**으로 실제 세이브 폴더를 지정하세요. `Lua/pz_status.txt`가 있는 폴더의 상위입니다.
2. **서버에 퐁듀 모드가 없거나 구버전** — 티어 파일(`pongdu_tiers.txt`)은 모드가 씁니다.
3. **모든 티어가 0** — 샌드박스에서 기능 금액이 전부 0이면 유효한 티어가 0개라 통과하지 못합니다.

## 후원했는데 인게임에서 아무 반응이 없음

1. 후원 금액이 **서버 티어에 정확히 일치**하는지 확인 (이상/이하가 아니라 완전 일치)
2. 메인 창의 리워드 티어 목록에 그 금액이 실제로 떠 있는지 확인 — 서버장이 해당 기능을 0으로 꺼뒀다면 목록에 없습니다
3. **테스트 후원**으로 같은 금액을 주입해서, 런처 문제인지 모드 문제인지 구분

## 리워드 티어를 런처에서 못 바꿈

의도된 동작입니다. 티어는 **서버장이 퐁듀 모드 샌드박스에서 정하고**, 런처는 읽기 전용으로 표시만 합니다. 자세한 내용은 [리워드 티어](reward-tiers.md) 참고.

시즌 도중에 서버장이 금액을 바꾸면 런처를 재시작하지 않아도 3초 안에 목록이 갱신됩니다.

## 게임 최적화가 적용되지 않음

| 증상 | 원인 / 대처 |
| ---- | ----------- |
| 체크박스가 비활성이고 "패치 리소스(opt_conf) 없음" | 빌드 시 `opt_conf`가 exe에 포함되지 않음 |
| "게임 파일 없음: … (B41 아님?)" | B42이거나 게임 파일이 변형됨 — 안전을 위해 아무것도 건드리지 않습니다 |
| "ProjectZomboid64.json 없음" | PZ 설치 폴더가 잘못 지정됨 — **폴더 선택**으로 다시 지정 |
| "RAM 크기를 알 수 없음" | 힙 항목만 사용 불가. 나머지 항목은 정상 적용됩니다 |
| 적용해도 상태가 안 바뀜 | PZ가 실행 중이면 파일 교체가 안 됩니다 — 게임을 완전히 종료 후 재시도 |
| 관리자 권한 창이 뜸 | 게임이 `Program Files` 등에 설치됨 — UAC 승격을 허용해야 적용됩니다 |

## 최적화를 원래대로 되돌리고 싶음

최적화 설정 창에서 체크를 해제하고 **적용**을 누르면 `puppet_opt_backup/`에 보관된 원본으로 복원됩니다. 이 백업 폴더가 사라진 경우엔 복원이 불가능하며, Steam 라이브러리에서 해당 게임 우클릭 → **속성 → 로컬 파일 → 게임 파일 무결성 검사**로 복구해야 합니다.

## 방송 중에 연동이 끊김

- **PZ 종료 / 인게임 이탈** — 감지되면 자동으로 게이트 화면으로 돌아갑니다. 다시 접속하면 됩니다.
- **화이트리스트에서 제거됨** — 다음 토큰 갱신 시점(최대 1일)에 감지되어 연동이 멈춥니다.
- **네트워크 순단** — 자동 재접속합니다. 90초간 아무 패킷도 못 받으면 죽은 연결로 판정하고 강제 재접속하며, 재시도 간격은 5→10→20→40→60초로 늘어납니다.

방송을 껐다 켜는 것 자체는 연동에 영향이 없습니다. 세션은 방송 on/off와 무관하게 유지됩니다.
