# 개요

**퐁듀 런처**는 치지직(CHZZK) 실시간 후원을 감지해서 Project Zomboid B41 서버에 전달하는 데스크톱 릴레이 앱입니다. 게임 모드가 아니라 게임 밖에서 돌아가는 별도 프로그램이며, [퐁듀 모드](../mod-features/overview.md)(`t3chzzkDonation`)와 짝을 이뤄 동작합니다.

```
치지직 후원 → 퐁듀 런처 → rewards.txt → 퐁듀 모드 → 인게임 효과
```

## 창 구성

실행 흐름에 따라 두 개의 창을 순서대로 보여줍니다.

1. **게이트(런처)** — 치지직 로그인 → 화이트리스트 검증 → 생방송·인게임 접속·서버 리워드 설정 확인. 자세한 순서는 [최초 실행](../getting-started/first-run.md) 참고.
2. **메인 창** — 실제 연동이 진행되는 화면.

메인 창에서 연동을 중지하거나 PZ 종료·인게임 이탈이 감지되면 자동으로 게이트로 돌아갑니다.

## 메인 창에 있는 것

| 영역 | 내용 |
| ---- | ---- |
| 채널 | 로그인한 계정의 채널명 |
| rewards.txt 경로 | 게이트에서 정한 Zomboid 폴더 기준 고정 경로 (읽기 전용) |
| 연동 시작 / 중지 | 창이 뜬 직후 자동으로 시작됨 |
| 리워드 티어 | 서버가 정한 금액↔기능 목록. **편집 불가**, 서버 설정이 바뀌면 실시간 갱신 |
| 테스트 후원 | 실제 후원 없이 티어 하나를 골라 주입 |
| 실시간 도네 로그 | 수신한 후원과 처리 결과 |

## 보안 (참고)

Client Secret은 런처(exe)에 포함되지 않습니다. 토큰 교환과 화이트리스트 검사는 전부 퐁듀 인증 서버(Cloudflare Workers)를 거치므로, 런처를 디컴파일해도 Secret은 나오지 않고 화이트리스트 검사를 우회할 수도 없습니다.

## 설계 원칙 (참고)

치지직 수신부(`ChzzkOfficialSource`)와 게임 출력부(`ZomboidAdapter`)가 분리된 구조입니다. 그 사이를 `DonationWorker`가 연결하며, 다른 게임으로 확장할 여지를 열어두고 설계했습니다.
