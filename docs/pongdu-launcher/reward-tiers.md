# 리워드 티어

후원 금액과 인게임 기능(featureId)을 연결하는 설정입니다. **금액이 정확히 일치해야** 해당 기능이 발동합니다 (이상/이하 구간이 아닙니다).

!!! info "티어는 서버가 정합니다"

    예전에는 런처에서 스트리머가 직접 금액을 편집했지만, 지금은 **서버장이 퐁듀 모드 샌드박스 설정에서 정한 값 하나를 서버 전원이 공유**합니다. 런처에서는 편집할 수 없고 읽기 전용으로 표시만 됩니다.

## 어디서 정하나

서버 생성/편집 화면 → 샌드박스 옵션 → **퐁듀 - 메인** 탭에 기능별로 `Tier_<featureId>` 항목이 있습니다.

- 값은 원 단위 정수이고, **0으로 두면 그 서버에서는 해당 기능을 아예 쓰지 않습니다.** 런처 리워드 목록에도 표시되지 않습니다.
- 두 기능에 같은 금액을 지정하면 목록에서 **위쪽에 있는 기능이 우선**하고, 아래쪽은 무시됩니다(모드 로그에 경고가 남습니다).

## 티어가 런처까지 전달되는 경로

```
샌드박스 Tier_* → (게임 접속 시) 모드가 pongdu_tiers.txt 기록 → 런처가 읽어서 표시
```

`pongdu_tiers.txt`는 `rewards.txt`·`pz_status.txt`와 같은 `<Zomboid 폴더>/Lua/`에 생성됩니다.

파일이 쓰이는 시점은 두 가지입니다.

1. 게임에 접속할 때
2. 서버장이 게임 중 관리자 샌드박스 패널에서 **Apply**를 눌렀을 때

런처는 이 파일을 3초 간격으로 감시하고 있어서, 시즌 도중 서버장이 금액을 바꾸면 **런처를 껐다 켜지 않아도 메인 화면 목록이 즉시 갱신**됩니다.

## 테스트 후원

실제 후원 없이 기능을 테스트해볼 수 있습니다.

1. 메인 창의 "테스트 후원" 드롭다운에서 서버 티어 중 하나를 선택
2. **확인** 클릭 → 후원자명 "테스트후원자", 메시지 "테스트"로 `rewards.txt`에 즉시 기록

드롭다운 목록도 서버 티어를 따라가므로, 서버장이 금액을 바꾸면 선택지도 같이 바뀝니다. 이때 고르고 있던 금액이 새 목록에도 남아 있으면 선택 상태가 유지됩니다.

!!! tip

    테스트 주입도 실제 후원과 동일하게 `rewards.txt`를 거치기 때문에, 인게임에서 실제로 기능이 발동하는지까지 그대로 확인할 수 있습니다.
