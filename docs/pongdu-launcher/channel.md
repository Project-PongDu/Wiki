# 채널 연동

퐁듀는 치지직 공식 Open API를 통한 **OAuth2 로그인**으로 연동 대상 채널을 결정합니다. 채널 URL이나 이름을 직접 입력하는 방식은 더 이상 사용하지 않습니다.

!!! info "로그인한 계정 = 연동 채널"

    공식 API 세션은 로그인한 계정 본인 채널의 후원 이벤트만 구독할 수 있습니다. 그래서 임의 채널을 입력하는 개념 자체가 없고, "치지직 로그인" 버튼 하나로 채널 확인까지 한 번에 끝납니다.

## 로그인 방식

- **최초 로그인**: 게이트 화면의 **치지직 로그인** 버튼을 누르면 브라우저가 열리고, 치지직 로그인 후 자동으로 런처로 돌아옵니다(로컬 콜백 수신).
- **재실행 시 자동 로그인**: 로그인에 성공하면 Refresh Token이 `chzzk_donation_config.json`에 저장되어, 다음 실행부터는 브라우저를 띄우지 않고 조용히 자동 로그인을 시도합니다.
- **로그인 만료/무효화**: 자동 로그인이 실패하면 로그인 버튼이 다시 표시되고, 사유가 있으면 화면에 안내 문구가 뜹니다.
- **로그아웃**: 체크리스트 화면의 **로그아웃** 버튼으로 저장된 토큰을 지우고 다시 로그인 화면으로 돌아갈 수 있습니다.

Client Secret은 런처(exe)에 포함되지 않습니다. 토큰 교환은 전부 퐁듀 인증 서버(Cloudflare Workers, `pongdu-auth`)를 거치므로, 런처를 디컴파일해도 Secret은 나오지 않습니다.

## 화이트리스트 검증

화이트리스트 검사는 런처가 아니라 **인증 서버가 토큰 발급/갱신과 한 몸으로 수행**합니다. 런처(클라이언트)에는 화이트리스트 검사 코드 자체가 존재하지 않습니다.

- 로그인한 계정의 채널이 이번 시즌 화이트리스트에 없으면 **"시즌 참가 목록에 없는 채널입니다"** 오류가 뜨고, **다른 계정으로 로그인** 버튼으로 재시도할 수 있습니다.
- 연동 도중 화이트리스트에서 제거되면, 다음 토큰 갱신 시점(최대 1일 이내)에 자동으로 감지되어 연동이 멈추고 게이트 화면으로 돌아갑니다.

## 연동 상태 확인

로그인에 성공하면 아래 4가지 항목을 3초 간격으로 자동 갱신하며 보여줍니다. 모두 통과해야 **연동 시작** 버튼이 활성화됩니다.

| 상태 | 설명 |
| --- | --- |
| 치지직 로그인 완료 | 로그인 + 화이트리스트 통과 여부 |
| 생방송 중 | 채널이 현재 방송 중인지 |
| PZ 실행 중 | Project Zomboid 프로세스 감지 |
| 인게임 접속 완료 | 실제 서버 접속 여부 |

## 재접속 / 자동 시작

- 런처에서 체크리스트를 모두 통과해 메인 창으로 넘어가면, 메인 창은 뜨자마자(0.3초 뒤) 자동으로 연동을 시작합니다 — 별도로 "연동 시작" 버튼을 다시 누를 필요가 없습니다.
- Project Zomboid 종료가 감지되면 연동 중이던 메인 창은 자동으로 정리되고 게이트 화면으로 돌아갑니다.
