# PZ 게임 최적화

특수좀비 소환, 좀비 레인, 호드나이트처럼 좀비 개체수가 순간적으로 늘어나는 상황에 대비해, Project Zomboid의 좀비 연산 클래스와 메모리 설정을 패치하는 기능입니다.

!!! warning "자동으로 적용되지 않습니다"

    로그인 화면 하단의 **최적화 설정** 버튼으로 창을 열고, 항목을 체크한 뒤 **적용**을 눌렀을 때만 게임 파일이 바뀝니다. 퐁듀를 실행했다는 이유만으로 게임 파일을 건드리는 일은 없습니다.

!!! warning "B41 전용"

    Build 41 클래스 구조를 대상으로 합니다. 대상 원본 파일이 없는 항목(B42 등)은 창에서 비활성으로 표시되고 아예 건드리지 않습니다.

## 항목 5종

항목 단위로 개별 적용/해제할 수 있습니다. 체크하면 패치본으로 교체하고, 해제하면 백업된 원본으로 되돌립니다.

| 항목 | 교체 대상 |
| ---- | --------- |
| 청크 로딩 최적화 | `zombie/iso/IsoChunkMap.class` |
| 월드 업데이트 / 좀비 정렬 연산 최적화 | `zombie/iso/IsoWorld.class` 및 내부 클래스 5종 (`$CompDistToPlayer`, `$CompScoreToPlayer`, `$Frame`, `$MetaCell`, `$s_performance`) |
| 좀비 네트워크 패킷 최적화 | `zombie/popman/NetworkZombiePacker.class` |
| 좀비 개체수 연산 최적화 | `zombie/popman/ZombieCountOptimiser.class` |
| JVM 힙 메모리 = 전체 RAM의 절반 | `ProjectZomboid64.json`, `ProjectZomboid64.bat` |

!!! note "왜 파일 1개 = 체크박스 1개가 아닌가"

    `IsoWorld$*`는 `IsoWorld`의 내부 클래스라 서로 버전이 맞아야 합니다. 하나만 패치본이고 나머지가 원본이면 런타임에 게임이 죽습니다.

    `json`과 `bat`도 마찬가지로 "힙 크기" 하나를 두 실행 경로에 쓰는 것뿐이라, json만 바꾸면 bat으로 직접 실행하는 사람은 여전히 기본값 3GB로 돌아갑니다.

    그래서 **같이 움직여야만 하는 파일은 한 그룹**으로 묶고, 그룹 안에 실제로 교체되는 파일 목록을 창에 그대로 보여줍니다.

## 힙 크기 계산

전체 물리 RAM의 **절반**을 256MB 단위로 절사해서 씁니다. 최소값은 2048MB입니다. `-Xms`/`-Xmx` 양쪽 모두 이 값으로 치환됩니다.

## 설치 폴더 자동 탐지

Steam 설치를 기준으로 동작합니다.

1. 레지스트리(`HKCU\Software\Valve\Steam` 등)로 Steam 루트 탐색
2. 못 찾으면 `C:`~`H:` 드라이브의 `Steam` / `SteamLibrary` 폴더를 직접 스캔
3. 찾은 각 Steam 루트에서 `libraryfolders.vdf`를 파싱해 추가 라이브러리 폴더까지 전부 확인
4. `appmanifest_108600.acf`(PZ의 Steam AppID)가 있는 라이브러리를 우선 사용

자동 탐지가 실패하거나 비-Steam 설치라면 창 상단의 **폴더 선택**으로 직접 지정할 수 있습니다.

## 창을 열었을 때

디스크의 현재 상태를 읽어 체크박스를 맞춰줍니다.

| 체크박스 상태 | 의미 |
| ------------- | ---- |
| 체크됨 | 그 항목이 현재 패치 상태 |
| 해제됨 | 원본 상태 |
| 비활성 (사유 표시) | 적용 불가 — 게임 파일 없음 / 패치 리소스 없음 / RAM 크기 확인 불가 등 |

일부 파일만 패치된 어중간한 상태는 "해제됨"으로 표시됩니다. 그대로 체크하고 **적용**을 누르면 다시 전부 맞춰집니다.

## 백업과 복원

- 최초 적용 시 원본 파일이 게임 폴더 안 `puppet_opt_backup/`에 **한 번만** 백업됩니다. 이미 백업이 있으면 덮어쓰지 않으므로 원본이 보존됩니다.
- 체크를 해제하고 **적용**을 누르면 이 백업에서 원본을 복원합니다.
- 백업 폴더 자체가 사라졌다면 복원이 불가능하며, Steam의 **속성 → 로컬 파일 → 게임 파일 무결성 검사**로 복구해야 합니다.

## PZ 실행 중에는 적용 불가

게임이 켜져 있으면 클래스 파일을 교체할 수 없습니다. 게임을 완전히 종료한 뒤 적용하세요.

## 관리자 권한이 필요한 경우

게임이 `Program Files` 등 일반 권한으로 쓸 수 없는 경로에 설치되어 있으면, **적용**을 누를 때 Windows UAC 승격 창이 뜹니다. 퐁듀 자기 자신을 `--pz-optimize` / `--pz-restore` 플래그로 관리자 권한 재실행하는 방식이며, 이 승격 프로세스는 퐁듀 본체를 종료하지 않고 별도로 동작합니다. 승격 창에서 선택한 항목 구성이 그대로 전달됩니다.
