# 저장 위치

퐁듀 런처와 퐁듀 모드는 **Project Zomboid 세이브 폴더**를 통해 정보를 주고받습니다. 설정과 로그인 정보도 이 폴더에 저장됩니다.

보통은 자동으로 찾아내므로 신경 쓸 필요가 없습니다.

!!! tip "실행파일 위치는 상관없습니다"

    설정이 세이브 폴더에 저장되므로, `PongDu.exe`를 다른 폴더로 옮기거나 새 버전으로 교체해도 로그인 정보와 설정이 그대로 유지됩니다.

## 폴더를 직접 지정해야 하는 경우

아래 상황에서는 자동 탐지가 빗나갈 수 있습니다.

- 세이브 폴더가 OneDrive로 옮겨진 경우
- 세이브 폴더를 다른 드라이브에 둔 경우
- 세이브 폴더를 여러 개 만들어 나눠 쓰는 경우
- 게임을 한 번도 실행한 적이 없는 경우 (먼저 게임을 한 번 실행하세요)

## 지정 방법

게이트 화면(연동 준비 확인)의 **Zomboid 폴더** 항목에서 **폴더 선택**을 누릅니다.

!!! warning "고를 폴더"

    `Lua` 폴더가 **들어 있는** 폴더를 골라야 합니다. `Lua` 폴더 자체가 아닙니다.

    예: `C:\Users\사용자\Zomboid`

한 번 지정하면 다음 실행부터 계속 그 폴더를 사용합니다. 이 설정 하나만 맞추면 "인게임 접속 완료"와 "서버 리워드 설정 확인"이 함께 해결됩니다.

## 확인하는 방법

폴더를 제대로 지정했다면, 게임에 접속한 뒤 몇 초 안에 준비 확인 항목이 초록색으로 바뀝니다. 게임에 접속했는데도 계속 회색이라면 폴더가 잘못 지정된 것입니다.
