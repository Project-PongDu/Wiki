# 파일 경로

퐁듀 런처와 퐁듀 모드는 **파일 3개**로 통신합니다. 셋 다 `<Zomboid 폴더>/Lua/` 아래에 있습니다.

| 파일 | 방향 | 용도 |
| ---- | ---- | ---- |
| `rewards.txt` | 런처 → 모드 | 후원 이벤트를 한 줄씩 기록 |
| `pz_status.txt` | 모드 → 런처 | 인게임 접속 상태 |
| `pongdu_tiers.txt` | 모드 → 런처 | 서버 [리워드 티어](reward-tiers.md) |

!!! info "폴더 하나만 맞추면 됩니다"

    예전에는 세 파일을 각자 따로 후보 경로 순회로 찾았습니다. 그래서 자동 탐지가 틀리면(별도 드라이브 세이브, 특이한 OneDrive 리다이렉트 등) 셋 다 동시에 어긋났습니다.

    지금은 **Zomboid 폴더 하나만 정하고** 나머지는 전부 거기서 상대경로로 파생시킵니다. 한 번만 바로잡으면 셋 다 같이 해결됩니다.

## 자동 탐지

런처는 실행할 때 아래 순서로 Zomboid 폴더를 찾습니다.

1. `~/Zomboid`
2. `%USERPROFILE%/Zomboid`
3. OneDrive로 리다이렉트된 경우: `%OneDrive%/Zomboid`, `%OneDriveConsumer%/Zomboid`
4. 위에서 못 찾으면 `C:`~`F:` 드라이브의 `Users/*/Zomboid`를 탐색

전부 실패하면 `~/Zomboid`를 그대로 씁니다 (게임을 아직 한 번도 실행하지 않아 폴더가 없는 경우).

## 수동 지정

게이트 화면(연동 준비 확인)의 **Zomboid 폴더** 항목에서 **폴더 선택**으로 직접 지정합니다. `Lua` 폴더가 들어 있는 **상위 폴더**를 골라야 합니다.

지정한 값은 설정 파일에 저장되어 다음 실행부터 자동 탐지 대신 그 경로를 씁니다.

!!! tip "세이브 폴더를 여러 개 쓰는 경우"

    `~/Zomboid`와 `~/Zomboid (b41)` 처럼 폴더를 나눠 쓰면, 런처 설정 파일도 양쪽에 생길 수 있습니다. 읽을 때는 수동 지정 폴더 쪽이 우선이고, 저장할 때는 존재하는 양쪽 모두에 씁니다.

!!! warning "경로가 없으면 연동도, 테스트도 불가"

    `rewards.txt` 경로가 비어 있으면 연동 시작과 테스트 후원 주입이 모두 막힙니다.

## rewards.txt 형식

한 줄에 후원 하나, 필드는 콤마로 구분된 4개입니다.

```
금액,featureId,후원자,메시지
```

- `featureId`가 비어 있으면(해당 금액에 매핑된 기능이 없으면) 모드 쪽에서는 통계 용도로만 기록되고 실제 인게임 효과는 발동하지 않습니다.
- 후원자명·메시지의 콤마, 줄바꿈, `%` 문자만 퍼센트 인코딩되고 한글을 포함한 나머지 유니코드는 UTF-8 원본 그대로 기록됩니다 (모드 쪽 Lua `urldecode`와 맞춰진 방식).
- 파일은 이어서 기록(append)됩니다. 폴더가 없으면 자동으로 생성합니다.

## pongdu_tiers.txt 형식

이름은 `.txt`지만 내용은 JSON입니다. 모드의 `getFileWriter`가 `ini/cfg/txt/log` 확장자만 허용해서 `.json`을 쓸 수 없기 때문입니다.

```json
{"server":"서버명","ts":1234567890,"tiers":{"1000":"buff_roulette","1100":"debuff_roulette"}}
```

런처는 이 파일을 3초 간격으로 감시하다가 변경되면 다시 읽습니다. 파일이 깨졌거나 모드가 쓰는 도중이라면 기존 값을 그대로 유지하고 다음 주기에 다시 시도합니다.
