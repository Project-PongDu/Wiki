# 자주 묻는 질문

## 설치 / 실행

### 퐁듀는 누구나 쓸 수 있나요?

아닙니다. 시즌에 참가하는 스트리머 채널 목록(화이트리스트)에 등재된 계정만 연동할 수 있습니다. 화이트리스트 검사는 퐁듀 인증 서버가 토큰 발급과 함께 수행하므로 클라이언트 조작으로 우회할 수 없습니다.

### 실행하니 백신 프로그램이 경고를 띄웁니다

PyInstaller로 묶은 서명되지 않은 exe라서 발생하는 오탐입니다. 코드 서명은 도입 예정입니다.

### 설정은 어디에 저장되나요?

실행파일 위치가 아니라 **Project Zomboid 세이브 폴더**(보통 `~/Zomboid`)에 저장됩니다. exe를 옮기거나 새 버전으로 교체해도 로그인 정보와 설정이 그대로 유지됩니다.

### 19세 방송에서도 되나요?

됩니다. 치지직 공식 Open API는 성인방송 여부와 무관하게 후원 이벤트를 전달합니다. 예전 버전에 있던 19세 차단과 NID 쿠키 입력은 제거되었습니다.

### macOS나 Linux에서 쓸 수 있나요?

지원하지 않습니다. 게임 최적화 기능이 Windows API에 의존합니다.

## 연동

### 방송을 껐다 켜면 연동이 끊기나요?

끊기지 않습니다. 세션은 방송 on/off와 무관하게 유지됩니다. "생방송 중" 조건은 연동을 **시작할 때만** 필요합니다.

### 후원 금액이 티어와 다르면 어떻게 되나요?

인게임 효과는 발동하지 않고 후원 기록만 남습니다. 금액은 **정확히 일치**해야 하며 "이상/이하" 구간이 아닙니다.

### 여러 명이 동시에 후원하면?

한 번에 하나씩 순서대로 처리됩니다. 대기 중인 후원은 화면의 후원 큐 박스에 쌓여서 표시됩니다.

### 세이프하우스 안에 있으면 안전한가요?

일부만 그렇습니다. 좀비를 소환하는 기능(좀비 룰렛, 뛰좀 소환, 특수좀비 소환)은 세이프존을 벗어날 때까지 대기하고, 미사일 폭격과 좀비 레인은 서버 설정에 따릅니다. 나머지는 세이프존 안에서도 그대로 발동합니다. 자세한 표는 [퐁듀 모드 개요](../mod-features/overview.md)에 있습니다.

## 리워드 티어

### 후원 금액은 제가 정하나요?

아닙니다. **서버장이 퐁듀 모드 샌드박스 설정에서 정합니다.** 같은 서버에 접속한 스트리머는 전원 같은 티어표를 공유하며, 런처에서는 읽기 전용으로 표시만 됩니다.

### 시즌 도중에 금액을 바꿀 수 있나요?

서버장이 게임 안 관리자 샌드박스 패널에서 값을 바꾸고 **Apply**를 누르면 됩니다. 각 스트리머의 런처는 3초 안에 자동으로 새 목록을 반영하므로 런처를 재시작할 필요가 없습니다.

### 특정 기능을 아예 끄고 싶습니다

샌드박스에서 해당 기능의 금액을 **0**으로 두면 됩니다. 그 서버에서는 발동하지 않고 런처 리워드 목록에도 표시되지 않습니다.

### 두 기능에 같은 금액을 넣으면?

목록에서 위쪽에 있는 기능이 우선하고 아래쪽은 무시됩니다. 모드 로그에 경고가 남습니다.

## 인게임

### 퐁듀 기능이 좀비를 불러모으나요?

원칙적으로 아닙니다. 총성·로터음·보급음 같은 연출은 클라이언트 로컬 사운드로만 재생하고 월드 사운드로 등록하지 않습니다.

예외는 [호드나이트](../mod-features/horde-night.md) 하나입니다. 원본 호드나이트의 실질 메커니즘이 스폰 마릿수가 아니라 유인 사운드이기 때문에 의도적으로 월드 사운드를 씁니다.

### 서버 후원과 개인 후원의 차이는?

개인 후원은 후원받은 스트리머 본인에게만, 서버 후원은 서버 접속자 전원에게 적용됩니다. 다만 서버 후원은 **서버장에게 후원했을 때만** 발동합니다. 서버장이 아닌 스트리머에게 들어오면 안내 메시지만 뜨고 소모됩니다.

### 미사일 폭격을 맞으면 차 안 아이템도 사라지나요?

사라지지 않습니다. 차량은 파츠 내구도가 0이 되고 문짝이 뜯기지만, 트렁크·시트·글로브박스 내용물은 그대로 남습니다.

### 게임 최적화는 꼭 해야 하나요?

필수는 아닙니다. 다만 좀비 레인·호드나이트처럼 개체수가 급증하는 기능을 쓸 계획이면 적용을 권장합니다. 원본은 자동 백업되고 언제든 되돌릴 수 있습니다.
