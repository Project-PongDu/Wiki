# 자주 묻는 질문

## 설치 / 실행

### 퐁듀는 어디서 받나요?

도입을 결정한 서버의 **디스코드 채널**에서 배포됩니다. 업데이트도 같은 채널로 공지됩니다.

### 퐁듀는 누구나 쓸 수 있나요?

아닙니다. 시즌에 참가하는 스트리머에게만 배포되며, 참가 목록에 등록된 계정으로 로그인해야 연동이 됩니다. 파일을 받았더라도 등록되지 않은 계정으로는 사용할 수 없습니다.

### 업데이트는 어떻게 하나요?

디스코드에 올라온 새 파일로 기존 `PongDu.exe`를 덮어쓰면 됩니다. 로그인 정보와 설정은 그대로 유지됩니다.

### 모드도 따로 설치해야 하나요?

스트리머는 설치할 필요가 없습니다. 서버에 접속하면 자동으로 받아집니다. 모드 설치는 서버장이 담당합니다.

### 실행하니 백신 프로그램이 경고를 띄웁니다

오탐입니다. 코드 서명이 아직 적용되지 않아 발생하며, 실행을 허용해도 됩니다.

### 설정은 어디에 저장되나요?

Project Zomboid 세이브 폴더에 저장됩니다. 실행파일을 옮기거나 새 버전으로 교체해도 로그인 정보와 설정이 그대로 유지됩니다.

### 19세 방송에서도 되나요?

됩니다.

### macOS나 Linux에서 쓸 수 있나요?

지원하지 않습니다. Windows 전용입니다.

## 연동

### 방송 중에 런처를 꺼도 되나요?

안 됩니다. 런처가 꺼져 있는 동안 들어온 후원은 인게임으로 전달되지 않습니다. 방송 중에는 계속 켜두세요.

### 방송을 껐다 켜면 연동이 끊기나요?

끊기지 않습니다. "생방송 중" 조건은 연동을 **시작할 때만** 필요합니다.

### 게임이 튕기면요?

게임 종료가 감지되면 자동으로 대기 화면으로 돌아갑니다. 다시 접속한 뒤 **연동 시작**을 누르면 됩니다.

### 후원 금액이 티어와 다르면 어떻게 되나요?

아무 일도 일어나지 않습니다. 금액은 **정확히 일치**해야 하며, 100원이라도 다르면 발동하지 않습니다.

### 여러 명이 동시에 후원하면?

한 번에 하나씩 순서대로 처리됩니다. 대기 중인 후원은 화면의 후원 큐 박스에 쌓입니다.

## 리워드 티어

### 후원 금액은 제가 정하나요?

아닙니다. **서버장이 정합니다.** 같은 서버의 스트리머는 전원 같은 금액표를 공유하며, 런처에서는 확인만 할 수 있습니다.

### 시즌 도중에 금액이 바뀌면요?

서버장이 바꾸면 런처 목록이 자동으로 갱신됩니다. 런처를 껐다 켤 필요가 없습니다. 화면이 바뀌면 시청자 안내도 함께 갱신하세요.

### 특정 기능만 빼고 싶습니다

서버장에게 요청하세요. 해당 기능의 금액을 0으로 두면 그 서버에서는 사용되지 않고 런처 목록에도 표시되지 않습니다.

## 인게임

### 세이프하우스 안에 있으면 안전한가요?

일부만 그렇습니다. 좀비를 소환하는 기능(좀비 룰렛, 뛰좀 소환, 특수좀비 소환)은 밖으로 나올 때까지 대기하고, 미사일 폭격과 좀비 레인은 서버 설정에 따릅니다. 나머지는 세이프하우스 안에서도 그대로 발동합니다.

자세한 표는 [퐁듀 모드 개요](../mod-features/overview.md)에 있습니다.

### 퐁듀 기능이 좀비를 불러모으나요?

효과음 때문에 좀비가 몰려오는 일은 없습니다. 예외는 [호드나이트](../mod-features/horde-night.md) 하나로, 좀비를 유인하는 것이 기능 자체의 목적입니다.

### 서버 후원인데 아무 일도 안 일어났습니다

서버 후원은 **서버장에게 후원했을 때만** 발동합니다. 서버장이 아닌 스트리머에게 들어오면 안내 메시지만 뜨고 소모됩니다. 시청자에게 미리 안내해 두는 편이 좋습니다.

### 미사일 폭격을 맞으면 차에 있던 짐도 사라지나요?

사라지지 않습니다. 차는 못 쓰게 되지만 트렁크·좌석·수납함의 아이템은 그대로 남습니다.

### 죽으면 짐을 다 잃나요?

[인벤토리 세이브 티켓](../mod-features/inv-save-ticket.md)을 가지고 있으면 부활 후 그대로 돌려받습니다. 없으면 일반 규칙대로 시체에 남습니다.

### 게임 최적화는 꼭 해야 하나요?

필수는 아닙니다. 다만 좀비 레인·호드나이트처럼 좀비가 대량으로 나오는 기능을 사용할 계획이면 권장합니다. 원본은 자동으로 백업되고 언제든 되돌릴 수 있습니다.
