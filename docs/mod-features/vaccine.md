# 백신

`vaccine` · 개인 후원

후원자 이름이 붙은 **좀복시비르 앰퓰**(`Zomboxivir`)을 인벤토리에 즉시 지급합니다. (예: `홍길동's 좀복시비르 앰퓰`)

우클릭으로 먹으면 **좀비 감염(Knox Infection)이 완전히 치료됩니다.** 감염 수치·치사 타이머뿐 아니라 물린 부위의 감염 플래그까지 전부 해제합니다.

!!! note "일반 상처 감염과는 다릅니다"

    상처 세균감염·식중독·감기는 [의약품 랜덤박스](medical-box.md)의 범용 치유제 주사기 담당입니다. 좀복시비르는 **좀비 감염 전용**입니다.

- 지급 시 보급음이 재생됩니다. 월드 사운드가 아니라 클라이언트 로컬 사운드라 **좀비 어그로가 붙지 않습니다.**
- 세이프존 안에서도 즉시 지급됩니다.
- 대기시간: `Delay_vaccine` (기본 3초)
