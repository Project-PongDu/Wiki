# 개요

**퐁듀 모드**는 치지직 후원을 인게임 효과로 바꿔주는 Project Zomboid 모드입니다. [퐁듀 런처](../pongdu-launcher/overview.md)와 짝을 이뤄 동작하며, 서버에 설치되어 있어야 합니다.

```
치지직 후원 → 퐁듀 런처 → 퐁듀 모드 → 인게임 효과
```

## 개인 후원 / 서버 후원

기능은 두 종류로 나뉩니다.

| 구분 | 적용 범위 | 발동 조건 |
| ---- | --------- | --------- |
| **개인 후원** | 후원받은 스트리머 본인 | 제한 없음 |
| **서버 후원** | 서버 접속자 **전원** | **서버장에게 후원**했을 때만 |

!!! warning "서버 후원은 서버장에게만"

    서버장이 아닌 스트리머에게 서버 후원 기능이 들어오면, 안내 메시지만 뜨고 효과 없이 소모됩니다. 시청자에게 안내할 때 이 점을 함께 알려주세요.

    서버장 판정은 서버 설정에 등록된 SteamID로 이루어집니다. 서버장이 `Host_AllowAdmin`을 켜두면 **어드민 권한을 가진 플레이어**도 서버 후원을 발동할 수 있습니다.

## 후원이 들어오면

### 순서대로 하나씩

후원이 여러 건 동시에 들어와도 **한 번에 하나씩** 처리됩니다. 대기 중인 후원은 화면의 후원 큐 박스에 순서대로 쌓입니다.

각 기능은 큐에 올라간 뒤 잠깐(기본 3초) 카운트다운한 다음 발동합니다. 시청자가 후원 효과가 나오는 순간을 볼 수 있도록 하는 시간입니다.

### 세이프하우스 안이라면

세이프하우스로 등록한 구역(및 주변 10타일) 안에 있으면, 일부 기능은 **밖으로 나올 때까지 대기**합니다. 대기 중인 후원은 큐 박스에 자물쇠로 표시됩니다.

| 정책 | 해당 기능 |
| ---- | --------- |
| 항상 즉시 발동 | 버프/디버프 룰렛, 식량 보급, 즉시 치유, 랜덤 부상, 백신, 랜덤 무기, 차량 공중보급, 스킬 각성제, 인벤토리 세이브 티켓, 랜덤 텔레포트, 화력지원, 의약품 랜덤박스, 블러드문, 호드나이트 |
| 나갈 때까지 대기 | 좀비 룰렛, 뛰좀 소환, 특수좀비 소환 |
| 서버 설정에 따름 | 미사일 폭격, 좀비 공습, 강령술 (셋 다 기본은 대기) |

[랜덤 텔레포트](random-teleport.md)는 세이프하우스와 무관하게 즉시 발동하지만, 도착 지점이 세이프하우스 안으로 잡히지는 않습니다.

### 겹치면 대기하는 조합

세이프하우스와 별개로, 서로 방해가 되는 조합은 앞선 기능이 끝날 때까지 대기합니다. 이때도 **관련 없는 다른 기능은 정상적으로 발동**합니다.

| 대기하는 기능 | 대기 조건 |
| ------------- | --------- |
| [랜덤 텔레포트](random-teleport.md) | 이전 텔레포트가 진행 중 / [좀비 공습](zombie-rain.md) 진행 중 / [화력지원](fire-support.md) 진행 중 |

좀비 공습과 화력지원은 발동한 자리를 기준으로 동작하기 때문에, 도중에 먼 거리로 이동하면 남은 효과가 사라집니다.

### 주변 사람도 알 수 있습니다

일부 기능의 효과음과 범위 표시는 근처(40타일 안)의 다른 플레이어에게도 전달됩니다. 효과음은 발동 지점에서 멀어질수록 작게 들립니다.

| 전달되는 것 | 해당 기능 |
| ------------ | --------- |
| 효과음 | 강령술, 좀비 공습, 랜덤 텔레포트, 미사일 폭격 |
| 바닥 범위 표시 | 강령술, 좀비 공습 |
| 머리 위 말풍선 ("OO 근처에 좀비다!") | 좀비 룰렛, 뛰좀 소환, 특수좀비 소환 |

### 좀비를 불러모으지 않습니다

퐁듀의 효과음(총성, 로터음, 보급음 등)은 좀비를 유인하지 않습니다. 후원 때문에 갑자기 좀비가 몰려오는 일은 없습니다.

단 [호드나이트](horde-night.md)는 예외로, 좀비를 유인하는 것이 기능 자체의 목적입니다.

## 서버 설정 (서버장용)

서버 생성/편집 화면의 샌드박스 옵션에 아래 탭이 추가됩니다.

| 탭 | 내용 |
| ---- | ---- |
| **퐁듀 - 메인** | 서버장 SteamID, 어드민 서버 후원 허용, 후원 패널 표시, **기능별 후원 금액** |
| **퐁듀 - 도움 효과** | 후원자에게 이득이 되는 기능 설정 |
| **퐁듀 - 방해 효과** | 후원자를 방해하는 기능 설정 |
| **퐁듀 - 서버 후원** | 호드나이트 / 블러드문 / 의약품 랜덤박스 |
| **퐁듀 - Dev** | 미사용·개발 중 기능 (히트맨, 화력지원 공수 등) |
| **히트맨 일반 설정** | 암살자(히트맨) NPC 공통 설정 |

모든 항목에 기본값이 들어 있으므로, 서버를 새로 만들면 별도 설정 없이 바로 사용할 수 있습니다.

!!! tip "먼저 설정할 것"

    **퐁듀 - 메인** 탭의 서버장 SteamID입니다. 이 값이 비어 있으면 서버 후원 기능이 동작하지 않습니다.

    SteamID 없이 IP로만 접속하는 서버는 서버장 판정을 할 수 없습니다. 이때는 `Host_AllowAdmin`을 켜고 서버장 계정에 어드민 권한을 주세요.

## 관리자 테스트 메뉴 (서버장용)

어드민 권한으로 **플레이어 캐릭터를 우클릭**하면 `[PongDu] (대상) 에게 후원효과 발동` 메뉴가 나타납니다. 도움 효과 / 방해 효과 / 서버 / Dev 분류에서 기능을 고르면, 그 플레이어에게 **가짜 후원 1건**이 들어간 것과 똑같이 동작합니다. (큐 박스 → 세이프하우스 대기 → 카운트다운 → 발동)

- 자기 자신을 우클릭하면 자신에게 발동합니다.
- 서버 분류는 대상이 서버 후원을 받을 수 있는 플레이어일 때만 보입니다.
- 빈 바닥을 우클릭하면 메뉴가 나타나지 않습니다.

## 애드온 모드 (서버장용) { #addon }

다른 모드가 퐁듀에 **서버 전용 후원 기능을 추가**할 수 있습니다. 애드온 모드를 함께 설치하면 그 기능의 금액·대기시간이 서버 설정에 추가되고, 스트리머의 런처 [리워드 티어](../pongdu-launcher/reward-tiers.md) 목록과 큐 박스에도 표시됩니다. 관리자 테스트 메뉴에서는 **애드온** 분류에 모입니다.

애드온 기능의 동작과 설정은 해당 애드온 모드 제작자에게 문의하세요.
