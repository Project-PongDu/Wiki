# 개요

**퐁듀 모드**(`t3chzzkDonation`)는 [퐁듀 런처](../pongdu-launcher/overview.md)가 기록한 `rewards.txt`를 읽어서, 후원 금액에 매핑된 **featureId**를 인게임 효과로 실행합니다. 금액↔featureId 매핑은 모드의 샌드박스 설정이 소유하므로, 같은 서버에 접속한 스트리머들은 전원 같은 티어표를 공유합니다.

```
치지직 후원 → 퐁듀 런처 → rewards.txt → 퐁듀 모드 → 인게임 효과
```

## 개인 후원 / 서버 후원

featureId는 **개인 후원**과 **서버 후원** 두 카테고리로 나뉩니다. 카테고리는 featureId의 고정 속성입니다.

| 카테고리      | 적용 범위                   | 발동 조건                                     |
| ------------- | --------------------------- | --------------------------------------------- |
| **개인 후원** | 후원받은 스트리머 본인      | 제한 없음                                     |
| **서버 후원** | 서버에 접속 중인 플레이어 전원 | **서버장에게 후원**했을 때만 발동             |

서버장 판정은 샌드박스 설정 `Host_SteamID`(SteamID64)와 대조해 **서버 측에서** 수행합니다. 서버장이 아닌 스트리머에게 서버 후원 기능이 들어오면 안내 메시지만 뜨고 소모됩니다.

## 발동 순서와 대기시간

후원이 여러 건 동시에 들어와도 **한 번에 하나씩** 순서대로 처리됩니다. 대기 중인 후원은 화면의 후원 큐 박스에 쌓여서 표시됩니다. (큐 박스 표시 자체는 샌드박스 `Donation_ShowPanel`로 끌 수 있습니다.)

각 기능은 큐에 올라간 뒤 **발동 대기시간**(샌드박스 `Delay_<featureId>`, 0~60초, 기본 3초)만큼 카운트다운한 다음 실제로 발동합니다. 0으로 설정하면 즉시 발동합니다.

## 세이프존 정책

플레이어가 **세이프하우스로 등록된 구역**(및 주변 10타일) 안에 있으면, 일부 기능은 그 구역을 벗어날 때까지 5초 간격으로 재확인하며 대기합니다. 대기 중인 슬롯은 큐 박스에 자물쇠로 표시됩니다.

| 정책                    | 해당 기능                                                                 |
| ----------------------- | ------------------------------------------------------------------------- |
| 항상 즉시 발동          | 버프/디버프 룰렛, 백신, 랜덤 무기, 차량 공중보급, 스킬 각성제, 인벤토리 세이브 티켓, 랜덤 텔레포트, 화력지원, 강령술, 의약품 랜덤박스, 블러드문, 호드나이트 |
| 항상 대기               | 좀비 룰렛, 뛰좀 소환, 특수좀비 소환                                       |
| 샌드박스 설정에 따름    | 미사일 폭격(`Bombard_SafeZoneBlock`, 기본 켜짐 = 대기), 좀비 레인(`Rain_SafeZoneBlock`, 기본 켜짐 = 대기) |

[랜덤 텔레포트](random-teleport.md)만 세이프존과 별개의 자체 락을 갖습니다 — 착지 검증이나 생존 복귀 카운트다운이 도는 동안에는 다음 랜덤 텔레포트가 대기합니다.

## 좀비 어그로 정책

퐁듀의 기능은 원칙적으로 **좀비 어그로를 유발하지 않습니다.** 총성·로터음·보급음 같은 연출은 클라이언트 로컬 사운드로만 재생하고 월드 사운드로 등록하지 않습니다.

예외는 [호드나이트](horde-night.md) 하나입니다. 원본 호드나이트의 실질 메커니즘이 스폰 마릿수가 아니라 유인 사운드이기 때문에 그쪽만 의도적으로 월드 사운드를 씁니다.

## 샌드박스 설정 탭

퐁듀 모드의 설정은 서버 생성/편집 화면의 샌드박스 옵션에 다음 탭으로 나뉘어 있습니다.

| 탭                    | 내용                                                    |
| --------------------- | ------------------------------------------------------- |
| **퐁듀 - 메인**       | 후원 패널 표시, 서버장 SteamID, **기능별 후원 금액(티어)** |
| **퐁듀 - 도움 효과**  | 후원자에게 이득이 되는 개인 후원 기능                   |
| **퐁듀 - 방해 효과**  | 후원자를 방해하는 개인 후원 기능                        |
| **퐁듀 - 서버 후원**  | 호드나이트 / 블러드문 / 의약품 랜덤박스                 |
| **퐁듀 - Dev**        | 미사용·개발 중 기능                                     |
| **Hitmans**           | 암살자 NPC 공통 설정                                    |

각 옵션은 샌드박스 자체에 기본값이 정의되어 있으므로, 서버를 새로 만들면 별도 설정 없이도 바로 동작합니다.
