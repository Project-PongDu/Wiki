# 개요

**퐁듀 모드**는 치지직 후원을 인게임 효과로 바꿔주는 Project Zomboid 모드입니다. [퐁듀 런처](../pongdu-launcher/overview.md)와 짝을 이뤄 동작하며, 서버에 설치되어 있어야 합니다.

```
치지직 후원 → 퐁듀 런처 → 퐁듀 모드 → 인게임 효과
```

## 개인 후원 / 서버 후원

기능은 두 종류로 나뉩니다.

| 구분 | 적용 범위 | 발동 조건 |
| ---- | --------- | --------- |
| **개인 후원** | 후원받은 스트리머 본인 | 제한 없음 |
| **서버 후원** | 서버 접속자 **전원** | **서버장에게 후원**했을 때만 |

!!! warning "서버 후원은 서버장에게만"

    서버장이 아닌 스트리머에게 서버 후원 기능이 들어오면, 안내 메시지만 뜨고 효과 없이 소모됩니다. 시청자에게 안내할 때 이 점을 함께 알려주세요.

    서버장 판정은 서버 설정에 등록된 SteamID로 이루어집니다.

## 후원이 들어오면

### 순서대로 하나씩

후원이 여러 건 동시에 들어와도 **한 번에 하나씩** 처리됩니다. 대기 중인 후원은 화면의 후원 큐 박스에 순서대로 쌓입니다.

각 기능은 큐에 올라간 뒤 잠깐(기본 3초) 카운트다운한 다음 발동합니다. 시청자가 후원 효과가 나오는 순간을 볼 수 있도록 하는 시간입니다.

### 세이프하우스 안이라면

세이프하우스로 등록한 구역(및 주변 10타일) 안에 있으면, 일부 기능은 **밖으로 나올 때까지 대기**합니다. 대기 중인 후원은 큐 박스에 자물쇠로 표시됩니다.

| 정책 | 해당 기능 |
| ---- | --------- |
| 항상 즉시 발동 | 버프/디버프 룰렛, 백신, 랜덤 무기, 차량 공중보급, 스킬 각성제, 인벤토리 세이브 티켓, 랜덤 텔레포트, 화력지원, 강령술, 의약품 랜덤박스, 블러드문, 호드나이트 |
| 나갈 때까지 대기 | 좀비 룰렛, 뛰좀 소환, 특수좀비 소환 |
| 서버 설정에 따름 | 미사일 폭격, 좀비 레인 (둘 다 기본은 대기) |

[랜덤 텔레포트](random-teleport.md)는 별도로, 이전 텔레포트가 아직 진행 중이면 다음 후원이 대기합니다.

### 좀비를 불러모으지 않습니다

퐁듀의 효과음(총성, 로터음, 보급음 등)은 좀비를 유인하지 않습니다. 후원 때문에 갑자기 좀비가 몰려오는 일은 없습니다.

단 [호드나이트](horde-night.md)는 예외로, 좀비를 유인하는 것이 기능 자체의 목적입니다.

## 서버 설정 (서버장용)

서버 생성/편집 화면의 샌드박스 옵션에 아래 탭이 추가됩니다.

| 탭 | 내용 |
| ---- | ---- |
| **퐁듀 - 메인** | 서버장 SteamID, 후원 패널 표시, **기능별 후원 금액** |
| **퐁듀 - 도움 효과** | 후원자에게 이득이 되는 기능 설정 |
| **퐁듀 - 방해 효과** | 후원자를 방해하는 기능 설정 |
| **퐁듀 - 서버 후원** | 호드나이트 / 블러드문 / 의약품 랜덤박스 |
| **퐁듀 - Dev** | 미사용·개발 중 기능 |
| **Hitmans** | 암살자 NPC 공통 설정 |

모든 항목에 기본값이 들어 있으므로, 서버를 새로 만들면 별도 설정 없이 바로 사용할 수 있습니다.

!!! tip "먼저 설정할 것"

    **퐁듀 - 메인** 탭의 서버장 SteamID입니다. 이 값이 비어 있으면 서버 후원 기능이 동작하지 않습니다.
