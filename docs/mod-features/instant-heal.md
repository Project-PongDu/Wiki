# 즉시 치유

`instant_heal` · 개인 후원

몸에 있는 **모든 부상을 그 자리에서 없애고** 부위별 체력을 가득 채웁니다. 캐릭터가 "상처가 사라졌다!"라고 외칩니다.

## 치료되는 것

긁힌 상처, 찢어진 상처, 깊은 상처, 물린 상처, 화상, 유리 파편, 박힌 총알, 골절, 출혈, 근육 뻐근함

붕대·봉합 상태도 함께 정리됩니다.

!!! warning "좀비 감염은 기본적으로 남습니다"

    상처는 사라져도 **좀비 감염은 그대로** 진행됩니다. 감염까지 치료하려면 [백신](vaccine.md)을 쓰세요.

    서버장이 `Heal_CureBiteInfection`을 켜두면 즉시 치유가 백신처럼 좀비 감염까지 치료합니다.

## 서버 설정

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Heal_CureBiteInfection` | - | 꺼짐 | 좀비 감염까지 치료 |
| `Delay_instant_heal` | 0~60 | 3 | 발동 대기시간 (초) |

- 치유음이 재생되지만 **좀비가 반응하지 않습니다.**
- 세이프하우스 안에서도 즉시 발동합니다.
