# 랜덤 텔레포트

`random_teleport` · 개인 후원

발동 시점의 위치를 원점으로, 일정 반경 링 안의 랜덤 좌표로 플레이어를 이동시킵니다.

## 좌표 검증

이동 지점이 물이나 벽 한가운데가 되지 않도록 2단계로 검증합니다.

1. **사전 검사** — 맵 바운딩 박스 밖, 존재하지 않는 지역을 미리 걸러냅니다.
2. **사후 검사** — 100타일 이상 떨어진 지점은 청크가 로드되기 전이라 미리 확인할 수 없습니다. 그래서 일단 이동한 뒤 청크 스트리밍이 끝나면 물타일 / 바닥 없음 / 솔리드(벽·나무) 여부를 확인하고, 부적합하면 원점 기준으로 재추첨해서 다시 이동합니다.

재추첨을 15회 초과하면 안전망으로 원점에 복귀시킵니다.

## 생존 복귀

`RT_Return`을 켜면, 착지 후 `RT_SurviveMinutes`분 동안 살아남으면 원래 위치로 자동 복귀합니다. 카운트다운이 화면에 표시됩니다.

## 샌드박스 옵션

| 옵션                    | 범위    | 기본값 | 설명                        |
| ----------------------- | ------- | ------ | --------------------------- |
| `RT_MinDist`            | 10~1000 | 100    | 최소 이동 거리 (타일)       |
| `RT_MaxDist`            | 20~2000 | 200    | 최대 이동 거리 (타일)       |
| `RT_Return`             | -       | 꺼짐   | 생존 시 원점 복귀           |
| `RT_SurviveMinutes`     | 1~60    | 5      | 복귀까지 생존해야 하는 시간 |
| `Delay_random_teleport` | 0~60    | 3      | 발동 대기시간 (초)          |

!!! info "자체 락"

    세이프존과는 무관하게 즉시 발동하지만, **착지 검증 중이거나 생존 복귀 카운트다운이 도는 동안**에는 다음 랜덤 텔레포트 후원이 큐 박스에서 자물쇠 상태로 대기합니다. 타이머가 끝나면 락이 풀리면서 다음 하나가 발동합니다.
