# 강화 혈청

`random_skill_potion` · 개인 후원

후원자 이름이 붙은 강화 혈청 1개를 인벤토리에 지급합니다. 마시면 해당 스킬의 레벨이 즉시 올라갑니다.

혈청은 **14개 스킬 × 3개 등급 = 42종**이 있습니다.

## 등급

| 등급 | 상승 레벨 | 추첨 가중치 |
| ---- | --------- | ----------- |
| 일반 | +1        | 10          |
| 희귀 | +2        | 3           |
| 특급 | +3        | 1           |

## 대상 스킬 (14종)

| 분류    | 스킬                                        |
| ------- | ------------------------------------------- |
| 체력    | 피트니스, 힘                                |
| 민첩    | 달리기, 경보, 날렵함, 은신                  |
| 근접무기 | 도끼, 둔기, 소형 둔기, 장검, 단검, 창       |
| 기타    | 정비, 조준                                  |

재장전(Reloading)은 의도적으로 제외되어 있습니다.

## 추첨 방식

1. 14개 스킬 중 하나를 **균등 확률**로 뽑습니다.
2. 그 스킬에 허용된 등급 안에서 **가중치 추첨**을 합니다.

## 샌드박스 옵션

스킬별로 획득 가능한 등급을 개별 제한할 수 있습니다. (`Serum_<스킬명>`)

| 설정값        | 획득 가능 등급        |
| ------------- | --------------------- |
| 일반+희귀+특급 | 3등급 전부 (기본값)  |
| 일반+희귀     | 특급 제외             |
| 일반만        | 일반만                |
| 획득 불가     | 해당 스킬 혈청 미출현 |

특급이 막히면 가중치 합이 13이 되어 자연스럽게 10:3 비율이 됩니다. 14개 스킬을 모두 "획득 불가"로 두면 후원이 들어와도 아무것도 지급되지 않습니다.

- 세이프존 안에서도 즉시 발동합니다.
- 대기시간: `Delay_random_skill_potion` (기본 3초)
