# 랜덤 부상

<p class="pd-meta"><span class="pd-tag pd-tag--personal">개인 후원</span><span class="pd-tag pd-tag--harm">방해 효과</span><span class="pd-id"><code>random_injury</code></span></p>

**무작위 부위에 무작위 부상**을 입힙니다. 캐릭터가 "(부위)에 (부상)!" 형태로 어디에 무엇을 입었는지 외칩니다.

- **머리와 목은 제외**됩니다. 한 번에 치명상이 되는 것을 막기 위해서입니다.
- 부상이 여러 개면 되도록 서로 다른 부위에 들어갑니다.
- 소리를 내지 않으므로 좀비가 몰려오지 않습니다.

## 나올 수 있는 부상

서버장이 켜둔 종류 중에서만 뽑힙니다. 기본값은 가벼운 두 종류만 켜져 있습니다.

| 부상 | 기본값 | 참고 |
| ---- | ------ | ---- |
| 긁힌 상처 | 켜짐 | |
| 찢어진 상처 | 켜짐 | |
| 깊은 상처 | 꺼짐 | 봉합 전까지 출혈이 오래 갑니다 |
| 유리 파편 | 꺼짐 | 깊은 상처 동반. 파편을 빼기 전엔 낫지 않습니다 |
| 물린 상처 | 꺼짐 | |
| 화상 | 꺼짐 | 물로 씻기 전까지 악화됩니다 |
| 총알 박힘 | 꺼짐 | 핀셋으로 빼내야 합니다 |
| 골절 | 꺼짐 | 서버의 골절 설정이 꺼져 있으면 뽑히지 않습니다 |

!!! info "좀비 감염은 기본적으로 없습니다"

    물린 상처가 나와도 기본 설정에서는 좀비 감염이 붙지 않습니다. 서버장이 `Injury_Infection`을 켜면 바닐라와 같은 확률(긁힘 7% / 찢어짐 25% / 물림 100%)로 감염됩니다.

    상처가 세균에 감염되는 일반 감염(항생제 대상)은 이 설정과 무관합니다.

## 서버 설정

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Injury_Count` | 1~10 | 1 | 후원 1건당 부상 개수 |
| `Injury_Infection` | - | 꺼짐 | 좀비 감염 허용 |
| `Injury_Scratch` | - | 켜짐 | 긁힌 상처 |
| `Injury_Cut` | - | 켜짐 | 찢어진 상처 |
| `Injury_DeepWound` | - | 꺼짐 | 깊은 상처 |
| `Injury_Glass` | - | 꺼짐 | 유리 파편 |
| `Injury_Bite` | - | 꺼짐 | 물린 상처 |
| `Injury_Burn` | - | 꺼짐 | 화상 |
| `Injury_Bullet` | - | 꺼짐 | 총알 박힘 |
| `Injury_Fracture` | - | 꺼짐 | 골절 |
| `Delay_random_injury` | 0~60 | 3 | 발동 대기시간 (초) |

부상 종류를 전부 끄면 아무 부상 없이 소모됩니다.

- 세이프하우스 안에서도 즉시 발동합니다.
