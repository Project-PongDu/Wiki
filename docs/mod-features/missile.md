# 미사일 폭격

`missile` · 개인 후원

지정 반경에 폭격을 가하는, 가장 파괴력 있는 개인 후원 기능입니다.

1. 발동 즉시 반경 40타일 내 플레이어들에게 경보음이 브로드캐스트됩니다.
2. 카운트다운 타이머가 화면에 표시됩니다.
3. 폭발 시:
     - 폭격 반경 내의 좀비를 전부 처치합니다. B41 멀티플레이 특성상 좀비는 **접속 중인 클라이언트가 소유권을 가진 개체만** 정상적으로 죽일 수 있어, 각 클라이언트가 자신이 소유한 좀비만 처리합니다.
     - 폭발 시점에 반경 안에서 실외에 있던 플레이어는 피해를 입습니다 — 머리 화상, 신체 부위 찰과상·열상·깊은 자상이 무작위로 적용되고 넘어짐 처리됩니다. (`Bombard_Injure`)

## 샌드박스 옵션

| 옵션                       | 범위   | 기본값 | 설명                                        |
| -------------------------- | ------ | ------ | ------------------------------------------- |
| `Bombard_Delay`            | 10~300 | 30     | 경보부터 폭발까지 카운트다운 (초)           |
| `Bombard_Radius`           | 5~60   | 30     | 폭격 반경 (타일)                            |
| `Bombard_Injure`           | -      | 켜짐   | 실외 플레이어 부상 여부                     |
| `Bombard_SafeZoneBlock`    | -      | 켜짐   | 세이프존 안에서는 벗어날 때까지 대기        |
| `Bombard_VehicleDamage`    | -      | 켜짐   | 반경 내 차량 피해 여부                      |
| `Delay_missile`            | 0~60   | 3      | 발동 대기시간 (초)                          |

!!! info "반경은 강령술과 별개"

    폭격 반경(`Bombard_Radius`)과 [강령술](rise-up-dead-man.md) 반경(`RiseUp_Radius`)은 기본값이 같을 뿐 서버 설정에서 완전히 독립된 변수입니다.
