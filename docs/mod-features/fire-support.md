# 화력지원 룰렛

`fire_support` · 개인 후원

주변 좀비를 정리해 주는 **지원 사격**입니다. 발동 시 아래 중 하나가 무작위로 뽑히며, 어떤 것이 나왔는지 캐릭터가 외칩니다.

| 종류 | 특징 |
| ---- | ---- |
| **저격** | 넓은 반경. 처치 수는 적지만 **특수좀비를 우선 사살**하고 관통 사격을 합니다 |
| **드론** | 플레이어 주위를 돌며 접근하는 좀비를 요격합니다. 지속시간이 가장 깁니다 |
| **헬기** | 넓은 반경에 기관총을 난사합니다. 지속시간이 짧습니다 |
| **공수** | 개발 중 |

!!! tip "[미사일 폭격](missile.md)과 달리 피해가 없습니다"

    지형, 건물, 차량, 바닥에 떨어진 아이템을 전혀 건드리지 않습니다. 거점 안에서 발동해도 안전합니다.

!!! info "총성이 들려도 좀비가 반응하지 않습니다"

    로터음이나 총성은 연출용이라 좀비를 불러모으지 않습니다.

!!! info "진행 중에는 랜덤 텔레포트가 대기합니다"

    헬기와 드론은 지원 대상이 갑자기 먼 거리로 이동하면 임무를 중단하고 돌아갑니다. 도중에 [랜덤 텔레포트](random-teleport.md)가 발동하면 남은 지원시간이 통째로 사라지는 셈입니다.

    그래서 화력지원이 끝날 때까지 랜덤 텔레포트 후원은 큐 박스에서 대기합니다. 다른 기능은 정상적으로 발동합니다.

## 서버 설정

### 공통

| 옵션 | 기본값 | 설명 |
| ---- | ------ | ---- |
| `FireSupport_Sniper` | 켜짐 | 저격 등장 |
| `FireSupport_Drone` | 켜짐 | 드론 등장 |
| `FireSupport_Helicopter` | 켜짐 | 헬기 등장 |
| `Delay_fire_support` | 3 | 발동 대기시간 (초) |

전부 끄면 저격이 나옵니다.

공수 등장 여부(`FireSupport_Airborne`)는 개발 중이라 **퐁듀 - Dev** 탭으로 옮겨졌습니다. 기본값 꺼짐 그대로 두세요.

### 저격

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Sniper_Radius` | 10~60 | 30 | 사격 반경 (타일) |
| `Sniper_Duration` | 10~120 | 30 | 지속 시간 (초) |
| `Sniper_Interval` | 200~10000 | 2000 | 사격 간격 (ms) |
| `Sniper_Pierce` | - | 켜짐 | 관통 사격 |
| `Sniper_PierceChance` | 0~100 | 80 | 관통 대상 사살 확률 (%) |
| `Sniper_KnockdownChance` | 0~100 | 50 | 넉다운 확률 (%) |

### 헬기 · 드론 데미지 방식

헬기와 드론은 한 발 한 발이 **크리티컬** 또는 **일반** 데미지로 들어갑니다.

- **크리티컬** — 기본값 6은 사실상 즉사입니다.
- **일반** — 좀비 체력을 조금씩 깎습니다. 여러 발 맞아야 쓰러집니다.

헬기는 넓은 범위를 제압하고, 드론은 플레이어에게 가장 위협적인 좀비(무는 중 → 달려드는 중 → 다가오는 중 순)를 먼저 노립니다. 기본값 기준 한 번 지원에 헬기는 100마리 안팎, 드론은 50마리 안팎을 처리하도록 맞춰져 있습니다.

좀비 체력 참고값: 보통 좀비 1.8~2.1, 튼튼한 좀비 3.5~3.8, 브루트 기본 5.0

### 드론

드론은 플레이어 주위 반경 5타일을 6초에 한 바퀴씩 돕니다. (고정값)

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Drone_Duration` | 10~120 | 60 | 지속 시간 (초) |
| `Drone_DetectRadius` | 4~40 | 20 | 표적 탐지 반경 (타일) |
| `Drone_Interval` | 10~2000 | 50 | 사격 간격 (ms) |
| `Drone_CritChance` | 0~100 | 2 | 크리티컬 확률 (%) |
| `Drone_CritDamage` | 0.1~100 | 6 | 크리티컬 한 발 데미지 (체력) |
| `Drone_NormalDamage` | 0~10 | 0.1 | 일반 한 발 데미지 (체력). 보통 좀비 약 20발 |
| `Drone_KnockdownChance` | 0~100 | 30 | 일반탄에 살아남은 좀비가 넘어질 확률 (%) |

!!! tip "드론 일반 데미지는 조금씩만 올리세요"

    드론은 발수가 많아서 일반 데미지를 조금만 올려도 처치 수가 크게 늘어납니다.

### 헬기

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Heli_Duration` | 10~120 | 30 | 지속 시간 (초) |
| `Heli_Radius` | 10~60 | 30 | 사격 반경 (타일) |
| `Heli_Interval` | 10~2000 | 150 | 사격 간격 (ms) |
| `Heli_CritChance` | 0~100 | 50 | 크리티컬 확률 (%) |
| `Heli_CritDamage` | 0.1~100 | 6 | 크리티컬 한 발 데미지 (체력) |
| `Heli_NormalDamage` | 0~10 | 0.43 | 일반 한 발 데미지 (체력). 보통 좀비 5발 |

- 저격·헬기·드론 모두 진행 중에 또 후원이 들어오면 지속시간이 연장됩니다.
- 헬기·드론은 지원받는 플레이어가 사망하거나 접속을 끊으면 그 자리에서 지원이 끝납니다.
- 세이프하우스 안에서도 즉시 발동합니다.
