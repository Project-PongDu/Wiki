# 화력지원 룰렛

`fire_support` · 개인 후원

[미사일 폭격](missile.md)과 달리 **환경 무피해** 지원 계열입니다. 지형·차량·시체 아이템을 건드리지 않고 반경 내 좀비만 처치합니다. 발동 시 4종 중 1종이 무작위로 뽑힙니다.

| 종류   | 성격        | 특징                                                       |
| ------ | ----------- | ---------------------------------------------------------- |
| 저격   | 지속 (중간) | 반경 넓음 / 킬 수 적음. **특수좀비 우선** 사살, 관통 사격  |
| 드론   | 지속 (김)   | 플레이어를 중심으로 시계방향 공전하며 사격                 |
| 헬기   | 지속 (짧음) | 반경 넓음, 로터음 루프 + 기관총 연사. 발당 킬 확률은 낮음  |
| 공수   | 개발 중     | 강하한 우호 병력이 좀비를 사격                             |

어떤 종류가 뽑혔는지는 후원받은 플레이어가 직접 외칩니다.

!!! info "어그로가 붙지 않습니다"

    로터음이나 총성을 크게 재생해도 월드 사운드로 등록하지 않기 때문에 좀비가 반응하지 않습니다.

## 공통 옵션

| 옵션                       | 기본값 | 설명                              |
| -------------------------- | ------ | --------------------------------- |
| `FireSupport_Sniper`       | 켜짐   | 저격을 룰렛 풀에 포함             |
| `FireSupport_Drone`        | 켜짐   | 드론을 룰렛 풀에 포함             |
| `FireSupport_Helicopter`   | 켜짐   | 헬기를 룰렛 풀에 포함             |
| `FireSupport_Airborne`     | 꺼짐   | 공수를 룰렛 풀에 포함 (개발 탭)   |
| `Delay_fire_support`       | 3      | 발동 대기시간 (초)                |

전부 해제하면 저격으로 폴백합니다.

## 저격

| 옵션                      | 범위     | 기본값 | 설명                       |
| ------------------------- | -------- | ------ | -------------------------- |
| `Sniper_Radius`           | 10~60    | 30     | 사격 반경 (타일)           |
| `Sniper_Duration`         | 10~120   | 30     | 지속 시간 (초)             |
| `Sniper_Interval`         | 200~10000 | 3000  | 사격 간격 (ms)             |
| `Sniper_Pierce`           | -        | 켜짐   | 관통 사격                  |
| `Sniper_PierceChance`     | 0~100    | 50     | 관통 대상 사살 확률 (%)    |
| `Sniper_KnockdownChance`  | 0~100    | 50     | 넉다운 확률 (%)            |
