# 블러드문

`blood_moon` · **서버 후원**

**서버장에게** 후원이 들어오면 일정 인게임 시간 동안 서버 전체가 핏빛으로 물들고, **모든 일반좀비가 스프린터로 변합니다.**

## 진행 중 걸리는 것

| 요소 | 내용 |
| ---- | ---- |
| 좀비 가속 | 일반좀비를 전부 스프린터로 변환. 종료 시 원래 속도로 복원 |
| 핏빛 조명 | 월드 전역 조명이 붉게 물듦. **낮에도 적용**되며 비·안개·폭풍 연출 위에 덮임 |
| 화면 틴트 | 화면 가장자리 비네트 오버레이 |
| 인디케이터 | 무들 스택에 남은 시간 표시 |
| 연출 | 시작 시 하울링 사운드 + 캐릭터 대사, 종료 시 종료 대사 |

[특수좀비](mutant-spawn.md)와 퐁듀가 소환한 좀비는 변환 대상에서 제외됩니다 — 원래 능력을 그대로 유지합니다.

## 중복 후원 = 연장

진행 중에 또 후원이 들어오면 **재시작이 아니라 남은 시간에 지속시간을 더합니다.** 재시작 방식이면 "남은 100분 → 120분"이 아니라 그냥 120분으로 리셋돼서, 두 번째 후원이 오히려 총 시간을 깎는 구간이 생기기 때문입니다.

연장 시에는 별도의 연장 사운드와 대사가 나오고, 조명은 현재 강도에서 이어서 다시 피크로 올라갑니다.

## 시간 기준

지속시간은 현실 시간이 아니라 **인게임 시간**입니다. 낮 길이(DayLength) 설정이나 배속 모드가 걸리면 함께 빨라집니다. 진행 상태는 서버 ModData에 저장되므로 **서버를 재시작해도 유지**됩니다.

## 샌드박스 옵션

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `BloodMoon_DurationMin` | 10~1440 | 120 | 지속 시간 (인게임 분) |
| `BloodMoon_ConvertZombies` | - | 켜짐 | 좀비 스프린터화 여부 |
| `BloodMoon_LightStrength` | 0~100 | 100 | 핏빛 조명 강도 (0이면 조명 연출 없음) |
| `BloodMoon_ShowIndicator` | - | 켜짐 | 무들 인디케이터 표시 |
| `Delay_blood_moon` | 0~60 | 3 | 발동 대기시간 (초) |

!!! warning "서버장 판정"

    [의약품 랜덤박스](medical-box.md)·[호드나이트](horde-night.md)와 동일하게 `Host_SteamID` 기준으로 서버가 판정합니다. 서버장이 아닌 스트리머에게 이 후원이 들어오면 안내 메시지만 뜨고 소모됩니다.

!!! info "어그로는 붙지 않습니다"

    좀비가 빨라질 뿐, 블러드문 자체가 좀비를 유인하지는 않습니다. 유인 사운드를 쓰는 건 [호드나이트](horde-night.md)뿐입니다.

- 세이프존 안에서도 즉시 발동합니다.
