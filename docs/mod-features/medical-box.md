# 의약품 랜덤박스

`medical_box` · **서버 후원**

**서버장에게** 후원이 들어오면, 서버에 접속 중인 **플레이어 전원**이 의약품 보급상자를 1개씩 받습니다.

상자는 각자 우클릭으로 개봉하며, 개봉하는 순간 주사기 4종 중 1개가 균등 확률로 뽑힙니다. 추첨은 상자마다 개별적으로 이루어지므로 두 사람이 같은 것을 받는다는 보장은 없습니다.

## 주사기 4종

| 주사기          | 효과                                                     |
| --------------- | -------------------------------------------------------- |
| 아드레날린      | 각성 효과                                                |
| 독시사이클린    | 식중독·독성·감기 및 상처 감염 제거                       |
| 모르핀          | 통증 완화                                                |
| 응급 주사기     | 즉효성 응급 처치                                         |

모든 주사기는 무게 0.01이고 **이동 중에도 사용할 수 있습니다.** 대신 응급 주사기를 제외하면 사용 시간이 일반 주사기의 10배입니다.

## 샌드박스 옵션

| 옵션                       | 기본값 | 설명                           |
| -------------------------- | ------ | ------------------------------ |
| `MedBox_Allow_Adrenaline`  | 켜짐   | 아드레날린을 추첨 풀에 포함    |
| `MedBox_Allow_Doxycycline` | 켜짐   | 독시사이클린을 추첨 풀에 포함  |
| `MedBox_Allow_Morphine`    | 켜짐   | 모르핀을 추첨 풀에 포함        |
| `MedBox_Allow_Emergency`   | 켜짐   | 응급 주사기를 추첨 풀에 포함   |
| `Delay_medical_box`        | 3      | 발동 대기시간 (초)             |

옵션은 개봉하는 시점에 읽으므로, 서버 운영 중에 바꿔도 즉시 반영됩니다. 4종을 모두 끄면 상자를 열어도 아무것도 나오지 않습니다.

!!! warning "서버장 판정"

    서버장 여부는 샌드박스 `Host_SteamID`(SteamID64)와 대조해 **서버 측에서** 판정합니다. 서버장이 아닌 스트리머에게 이 후원이 들어오면 안내 메시지만 뜨고 소모됩니다.

- 세이프존 안에서도 즉시 지급됩니다.
