# 의약품 랜덤박스

`medical_box` · **서버 후원**

**서버장에게** 후원이 들어오면, 서버에 접속 중인 **플레이어 전원**이 의약품 보급상자를 1개씩 받습니다.

상자는 각자 우클릭으로 개봉하며, 개봉하는 순간 아래 5종 중 1개가 균등 확률로 뽑힙니다. 추첨은 상자마다 개별적으로 이루어지므로 두 사람이 같은 것을 받는다는 보장은 없습니다.

## 추첨 풀 5종

| 아이템 | 효과 |
| ------ | ---- |
| 전투자극제 주사기 | 피로·지구력 즉시 회복. 빈사 상태면 체력도 소량 회복 |
| 범용 치유제 주사기 | 감기 + 식중독 + 시체 악취 메스꺼움 + 상처 세균감염 치료 |
| 급성 진통제 주사기 | 즉시 통증 0 + 2인게임시간 동안 통증 억제. 같은 시간 동안 팔 부상으로 인한 근접 공격속도 감소도 무시 |
| 응급 지혈제 주사기 | 즉시 회복은 없음. 지속시간 동안 **상처 드레인으로 인한 체력 감소만** 되돌림 |
| 좀복시비르 앰퓰 | 좀비 감염 완전 치료 ([백신](vaccine.md)과 동일한 아이템) |

주사기 4종은 무게 0.01이고 **이동 중에도 사용할 수 있습니다.** 대신 응급 지혈제를 제외하면 사용 시간이 일반 주사기의 10배입니다.

!!! info "응급 지혈제의 동작"

    주사 시점의 **부위별** 체력을 바닥값으로 잡아 그 아래로 내려가지 않게 막는 방식입니다. 자연회복은 그대로 반영되고(바닥값도 같이 올라감), 좀비 타격 같은 급성 피해도 그대로 들어갑니다(바닥값도 같이 내려감). 녹스 감염과 저체온은 예외라 그쪽으로는 정상적으로 죽습니다.

    전투자극제는 이식 원본(FirstAidOverhaul)에 있던 배고픔·갈증·패닉 부작용을 제거한 상태입니다.

## 샌드박스 옵션

| 옵션                       | 기본값 | 설명                              |
| -------------------------- | ------ | --------------------------------- |
| `MedBox_Allow_Adrenaline`  | 켜짐   | 전투자극제를 추첨 풀에 포함       |
| `MedBox_Allow_Doxycycline` | 켜짐   | 범용 치유제를 추첨 풀에 포함      |
| `MedBox_Allow_Morphine`    | 켜짐   | 급성 진통제를 추첨 풀에 포함      |
| `MedBox_Allow_Emergency`   | 켜짐   | 응급 지혈제를 추첨 풀에 포함      |
| `MedBox_Allow_Vaccine`     | 켜짐   | 좀복시비르 앰퓰을 추첨 풀에 포함  |
| `Delay_medical_box`        | 3      | 발동 대기시간 (초)                |

옵션은 개봉하는 시점에 읽으므로, 서버 운영 중에 바꿔도 즉시 반영됩니다. 5종을 모두 끄면 상자를 열어도 아무것도 나오지 않습니다.

!!! warning "서버장 판정"

    서버장 여부는 샌드박스 `Host_SteamID`(SteamID64)와 대조해 **서버 측에서** 판정합니다. 서버장이 아닌 스트리머에게 이 후원이 들어오면 안내 메시지만 뜨고 소모됩니다.

- 세이프존 안에서도 즉시 지급됩니다.
