# 랜덤 무기

`random_weapon` · 개인 후원

**근접 무기 상자** 또는 **원거리 무기 상자**를 50:50 확률로 지급합니다. 상자를 우클릭해서 개봉하면 무기 1개가 나옵니다.

## 근접 무기 상자

먼저 6개 근접 스킬 계열 중 하나를 가중 추첨한 뒤, 그 계열에 속하는 **모든 스크립트 아이템 중에서 균등하게** 하나를 뽑습니다. 무기 목록을 손으로 관리하지 않고 런타임에 게임 스크립트에서 직접 수집하므로, 무기를 추가하는 모드를 켜면 그 무기들도 자동으로 후보에 포함됩니다.

| 계열      | 가중치 |
| --------- | ------ |
| 소형 둔기 | 25     |
| 단검      | 20     |
| 둔기      | 20     |
| 창        | 15     |
| 도끼      | 12     |
| 장검      | 8      |

풀에서 제외되는 것: 무기가 아닌 아이템, 폐기(OBSOLETE) 아이템, 급조(Improvised) 아이템. 단 **창은 예외**로 급조 아이템도 포함됩니다 — 대부분의 창이 "급조" 태그를 달고 있고 실제로도 정상적인 무기이기 때문입니다.

## 원거리 무기 상자

총기 1정과 함께 **탄창 2개 + 탄약 상자 3개**를 같이 지급합니다. 탄창/탄약 종류는 총기 스크립트에서 직접 읽어오므로 총기별 대응표가 필요 없습니다.

| 환경                       | 풀 구성                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------- |
| Arsenal Gunfighter 사용 시 | Arsenal의 샌드박스 설정(총기 종류/출처/구경)이 적용된 **루트 분포 테이블**을 스캔해서 구성. 즉 서버에서 비활성화한 총은 나오지 않습니다. |
| 바닐라                     | 내장 가중치 표                                                                          |

- 세이프존 안에서도 즉시 발동합니다.
- 대기시간: `Delay_random_weapon` (기본 3초)
