# 강령술

`rise_up_dead_man` · 개인 후원

플레이어 주변 반경 안의 **좀비 시체를 되살립니다.**

- 원래 뛰는 좀비였다면 되살아난 뒤에도 뛰는 좀비입니다.
- [특수좀비](mutant-spawn.md)였다면 종류와 능력까지 그대로 되살아납니다. 서버를 재시작해도 유지됩니다.

!!! danger "시체를 쌓아두지 마세요"

    시체가 많이 쌓인 곳에서 발동하면 그 자리에서 좀비 무리가 만들어집니다. 이 기능이 들어올 만한 금액대로 방송한다면 시체를 미리 치워두는 것이 좋습니다.

    세이프하우스로 등록해 둔 거점은 아래 대기 처리로 보호되지만, **등록하지 않은 거점은 보호되지 않습니다.**

## 연출 방식

서버 설정 `RiseUp_Style`로 연출을 고릅니다. **연출만 다를 뿐** 되살아나는 범위와 마릿수는 같습니다.

| 방식 | 연출 |
| ---- | ---- |
| **강령술** (기본) | 바닥에 보라색 원으로 부활 범위가 표시되고 오컬트 효과음이 재생됩니다 |
| **재활성화 가스 살포** | 바닥에 보라색 가스가 반경만큼 퍼졌다가 걷힙니다. 캐니스터 살포음이 재생됩니다 |

가스는 연출일 뿐 피해를 주거나 좀비를 불러모으지 않습니다.

범위 표시와 효과음은 근처에 있는 다른 플레이어에게도 보이고 들립니다.

## 시체가 부족하면 대기합니다

반경 안의 시체가 **최소 시체 수**(기본 10구)보다 적으면 발동하지 않고 기다립니다. 후원은 사라지지 않습니다.

- 대기 중에는 화면 우측 상태 아이콘에 **강령술 대기** 아이콘이 뜹니다. 좌하단에 `현재/필요` 시체 수가 표시되고, 필요 수에 가까워질수록 아이콘이 강하게 흔들립니다.
- 시체가 채워지는 순간 자동으로 발동합니다.
- 대기 중에 재접속해도 대기 상태가 유지됩니다.
- 대기 아이콘은 후원받은 본인 화면에만 보입니다.

## 한 번에 되살아나는 수

1회에 되살아나는 좀비는 **최대 부활 수**(기본 100마리)까지입니다. 반경 안 시체가 그보다 많으면 일부만 되살아납니다.

어떤 시체를 고를지는 `RiseUp_Priority`로 정합니다.

| 우선순위 | 동작 |
| -------- | ---- |
| 완전 무작위 | 반경 안 시체 중 무작위 |
| **특수좀비 우선** (기본) | 특수좀비 시체를 먼저 채우고 남는 자리를 일반 좀비로 채움 |

## 서버 설정

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `RiseUp_Style` | - | 강령술 | 연출 방식 (강령술 / 재활성화 가스 살포) |
| `RiseUp_GasDuration` | 3~15 | 7 | 가스가 퍼졌다 걷힐 때까지 시간 (초). 가스 방식만 |
| `RiseUp_Radius` | 5~60 | 30 | 부활 반경 (타일) |
| `RiseUp_ShowRadius` | - | 켜짐 | 보라색 원 범위 표시. 강령술 방식만 (가스는 항상 표시) |
| `RiseUp_SafeZoneBlock` | - | 켜짐 | 세이프하우스 안이면 나올 때까지 대기 |
| `RiseUp_MinCorpses` | 0~200 | 10 | 최소 시체 수. 0이면 시체 수와 무관하게 즉시 발동 |
| `RiseUp_MaxRevive` | 0~500 | 100 | 1회 최대 부활 수. 0이면 제한 없음 |
| `RiseUp_Priority` | - | 특수좀비 우선 | 최대 부활 수를 넘을 때 고르는 방식 |
| `Delay_rise_up_dead_man` | 0~60 | 3 | 발동 대기시간 (초) |

!!! warning "최대 부활 수를 0으로 두지 마세요"

    제한이 없으면 시체 더미 전체가 한 번에 일어나 서버 부하가 크게 늘어납니다.

!!! info "세이프하우스 안에서는 대기합니다"

    `RiseUp_SafeZoneBlock`이 켜져 있으면(기본) 세이프하우스 구역(및 주변 10타일) 안에서는 **밖으로 나올 때까지 발동하지 않습니다.** 대기 중인 후원은 큐 박스에 자물쇠로 표시됩니다.

    시체 수 대기 중에 세이프하우스로 들어가도 마찬가지로 발동이 멈춥니다.

    서버장이 이 옵션을 끄면 세이프하우스 안에서도 그대로 발동합니다.
