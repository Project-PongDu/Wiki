# 강령술

`rise_up_dead_man` · 개인 후원

플레이어 주변 반경 내의 좀비 시체를 모두 되살립니다.

- 시전 시 화면에 발동 범위가 바닥 마커로 약 3초간 표시됩니다. (마커는 후원받은 본인 화면에만 보입니다)
- 되살아난 좀비가 원래 스프린터였다면 부활 후에도 스프린터 속도를 유지합니다.
- 되살아난 개체가 [특수좀비](mutant-spawn.md)였다면 종류·능력까지 그대로 복원됩니다. 시체(`IsoDeadBody`)가 원래 좀비의 데이터를 자동으로 물려받기 때문에, 서버가 재시작되어도 유지됩니다.

## 샌드박스 옵션

| 옵션                      | 범위 | 기본값 | 설명               |
| ------------------------- | ---- | ------ | ------------------ |
| `RiseUp_Radius`           | 5~60 | 30     | 부활 반경 (타일)   |
| `Delay_rise_up_dead_man`  | 0~60 | 3      | 발동 대기시간 (초) |

!!! note "권한 구조"

    좀비는 클라이언트 권한이지만 **시체는 서버 권한**입니다. 그래서 부활 처리는 서버 한 곳에서만 수행되며, 클라이언트 수만큼 좀비가 중복 생성되는 일은 없습니다.

- 세이프존 안에서도 즉시 발동합니다.
