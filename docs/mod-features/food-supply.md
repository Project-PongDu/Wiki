# 식량 보급

<p class="pd-meta"><span class="pd-tag pd-tag--personal">개인 후원</span><span class="pd-tag pd-tag--help">도움 효과</span><span class="pd-id"><code>food_supply</code></span></p>

서버장이 정한 **음식 아이템을 정해진 개수만큼** 인벤토리에 바로 넣어줍니다. 기본은 감자칩 5개입니다.

- 지급된 아이템에는 후원자 이름이 붙습니다.
- 지급 시 보급음이 재생되지만 **좀비가 반응하지 않습니다.**
- 무게 제한을 넘어도 강제로 들어갑니다. 짐이 무거워질 수 있으니 확인하세요.

## 서버 설정

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `FoodSupply_Item` | - | `Base.Crisps` | 지급할 아이템 (모듈명 포함 풀네임) |
| `FoodSupply_Count` | 1~50 | 5 | 후원 1건당 지급 개수 |
| `Delay_food_supply` | 0~60 | 3 | 발동 대기시간 (초) |

!!! tip "다른 모드 아이템도 넣을 수 있습니다"

    `FoodSupply_Item`에는 바닐라뿐 아니라 서버에 설치된 **다른 모드의 아이템**도 적을 수 있습니다. 서버 전용 시그니처 음식을 만들어 후원 보상으로 쓰는 식입니다.

    이름을 잘못 적었거나 해당 모드가 꺼져 있으면 후원이 사라지지 않도록 **감자칩으로 대신 지급**됩니다.

- 세이프하우스 안에서도 즉시 지급됩니다.
