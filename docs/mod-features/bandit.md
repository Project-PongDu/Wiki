# 암살자 파견

`bandit_melee` / `bandit_ranged` · 개인 후원

!!! warning "기본값은 꺼져 있습니다"

    `Tier_bandit_melee` / `Tier_bandit_ranged`의 기본 금액이 **0**이라 사용하지 않는 상태입니다. 쓰려면 서버장이 샌드박스 **퐁듀 - 메인** 탭에서 금액을 직접 지정해야 합니다. NPC 동작 관련 옵션은 **퐁듀 - Dev** 탭과 **Hitmans** 탭에 있습니다.

무장한 적대 NPC 클랜을 소환합니다. 다른 모드(Bandits)와의 데이터 충돌을 피하기 위해 독립된 네임스페이스로 구현된 자체 NPC 시스템을 사용합니다.

| featureId       | 구성                                                                  |
| --------------- | --------------------------------------------------------------------- |
| `bandit_melee`  | 근접무기 위주로 무장한 **4인** 클랜                                   |
| `bandit_ranged` | 원거리 화기 위주로 무장한 **2인** 클랜. 저격 전문성을 가진 개체 포함  |

- 소환된 NPC 근처에 일정 시간 동안 "{후원자}의 암살자" 표식이 표시됩니다.
- 스폰이 몰릴 경우 대기열에 쌓였다가 순서대로 처리됩니다.
- 세이프존 안에서도 즉시 발동합니다.
- 대기시간: `Delay_bandit_melee` / `Delay_bandit_ranged` (기본 3초)

NPC 공통 동작(출혈, 감염, 바리케이드 제거, 대사, 자막 등)은 샌드박스 **Hitmans** 탭에서 조정합니다.
