# 차량 공중보급

<p class="pd-meta"><span class="pd-tag pd-tag--personal">개인 후원</span><span class="pd-tag pd-tag--help">도움 효과</span><span class="pd-id"><code>vehicle_drop</code></span></p>

**차량 보급 키트**를 지급합니다. 우클릭으로 개봉하면 근처 빈 공터에 차량 1대가 무작위로 투하되고, 캐릭터가 투하 위치 좌표를 외칩니다.

투하 지점은 실외이면서 물·장애물·다른 차량이 없는 곳으로 자동 선택됩니다.

- 투하된 차량 주변에는 **낙하산**이 흩어져 있습니다. 차에 타면 낙하산은 자동으로 치워집니다.
- **지도에 투하 위치가 파란 마커로 표시**됩니다. 큰 지도와 미니맵 모두에 보이며, 차에 타면 마커가 사라집니다.

!!! tip "좌표를 놓쳤다면"

    지도의 파란 마커를 확인하세요. 캐릭터가 외치는 좌표는 채팅 로그에도 남습니다.

## 서버 설정

| 옵션 | 기본값 | 설명 |
| ---- | ------ | ---- |
| `VehicleDrop_Source` | 모드 차량만 | 바닐라만 / 모드만 / 바닐라+모드 / 군용 차량만 |
| `VehicleDrop_Pool` | (비어 있음) | 나오게 할 차종을 직접 추가. `;`로 구분 |
| `VehicleDrop_ExcludePool` | 화력지원용 드론·헬기 | 나오지 않게 할 차종. `;`로 구분 |
| `VehicleDrop_MinDistance` | 10 | 투하 지점 최소 거리 (타일) |
| `VehicleDrop_MaxDistance` | 20 | 투하 지점 최대 거리 (타일) |
| `VehicleDrop_BlockModNaturalSpawn` | 꺼짐 | 모드 차량이 월드에 자연 생성되지 않게 함 |
| `Delay_vehicle_drop` | 3 | 발동 대기시간 (초) |

`VehicleDrop_Pool`에 직접 적은 차량은 위 분류 설정과 무관하게 무조건 후보에 포함됩니다.

나올 수 있는 차량이 하나도 없으면 차량 대신 안내 메시지만 표시됩니다.

투하 지점을 최대 거리 안에서 못 찾으면 플레이어 발밑에 투하됩니다. 최소 거리가 최대 거리보다 크면 두 값을 서로 바꿔 적용합니다.

!!! tip "좋은 모드 차량을 후원 전용으로"

    `VehicleDrop_BlockModNaturalSpawn`을 켜면 모드가 추가한 차량이 맵에 자연 생성되지 않아, **차량 공중보급으로만** 얻을 수 있게 됩니다. 바닐라 차량은 영향이 없습니다.

    이미 맵에 생성된 차량은 사라지지 않으므로 **새 서버를 열기 전에** 설정하세요.

- 세이프하우스 안에서도 즉시 발동합니다.
