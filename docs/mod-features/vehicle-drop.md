# 차량 공중보급

`vehicle_drop` · 개인 후원

**차량 보급 키트**를 지급합니다. 우클릭으로 개봉하면 플레이어 근처의 조건에 맞는 실외 지점을 찾아 차량 1대를 무작위로 소환하고, 투하 위치 좌표를 외칩니다.

투하 지점은 5×5 타일이 전부 실외이고, 물·장애물·다른 차량이 없어야 합니다.

## 차종 선택

샌드박스 `VehicleDrop_Source`로 기본 풀을 정하고, 거기에 `VehicleDrop_Pool`(수동 입력)을 **합집합**으로 얹은 뒤 무작위 선택합니다. 수동 입력은 드롭다운 필터를 무시합니다 — 직접 적은 차량은 무조건 채택됩니다.

| 옵션                        | 기본값                                 | 설명                                                        |
| --------------------------- | -------------------------------------- | ----------------------------------------------------------- |
| `VehicleDrop_Source`        | 모드 차량만                            | 바닐라만 / 모드만 / 바닐라+모드 / 군용 차량만               |
| `VehicleDrop_Pool`          | (비어 있음)                            | 수동 추가 차종. `;`로 구분                                  |
| `VehicleDrop_ExcludePool`   | `Base.PongDuDrone;Base.PongDuHeli`     | 제외 차종. [화력지원](fire-support.md)용 기체가 기본 제외됨 |
| `VehicleDrop_MinDistance`   | 30                                     | 투하 지점 최소 거리 (타일)                                  |
| `VehicleDrop_MaxDistance`   | 50                                     | 투하 지점 최대 거리 (타일)                                  |
| `Delay_vehicle_drop`        | 3                                      | 발동 대기시간 (초)                                          |

최종 후보가 0개면 차량을 소환하지 않고 "보급 가능한 차량 없음" 안내만 표시합니다.

- 세이프존 안에서도 즉시 발동합니다.
