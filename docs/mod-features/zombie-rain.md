# 좀비 공습

<p class="pd-meta"><span class="pd-tag pd-tag--personal">개인 후원</span><span class="pd-tag pd-tag--harm">방해 효과</span><span class="pd-id"><code>zombie_rain</code></span></p>

플레이어 주변에 **좀비가 하늘에서 떨어집니다.** 정해진 시간 동안 계속 낙하하며, 남은 시간이 화면에 표시됩니다.

!!! note "이전 이름은 좀비 레인"

    기능 이름이 **좀비 레인 → 좀비 공습**으로 바뀌었습니다. "좀비 레인"은 이제 공습 방식 중 하나의 이름입니다.

## 공습 방식

서버 설정 `Rain_Style`로 연출을 고릅니다. 떨어지는 좀비 수와 종류는 방식과 무관하게 같습니다.

| 방식 | 연출 |
| ---- | ---- |
| **좀비 레인** (기본) | 플레이어를 중심으로 반경 곳곳에서 떨어집니다. 낙하 반경이 바닥에 표시됩니다 |
| **좀비 공중투하** | 수송기 그림자가 플레이어 근처를 한 번 가로지르며, 그림자 주변에 순서대로 떨어뜨립니다. 엔진음이 들립니다 |

화면 카운터에는 공습 방식 이름(좀비 레인 / 좀비 공중투하)이 표시됩니다.

## 낙하

- 좀비는 **7층 높이**에서 떨어집니다. 낙하하는 동안 팔다리를 벌린 자세로 내려옵니다.
- **착지 피해가 없습니다.** 떨어진 좀비는 서버 설정 체력 그대로 멀쩡하게 일어납니다. 자유낙하한 좀비는 착지할 때 잠깐 넘어졌다 일어납니다.
- 건물이 없는 **야외에만** 떨어집니다.

서버장이 `Rain_Parachute`를 켜두면 좀비가 **낙하산을 메고 천천히** 내려옵니다(7층 기준 약 6초). 착지하거나 공중에서 사살되면 낙하산은 사라지고 남지 않습니다.

!!! danger "실내로 피해도 소용없습니다"

    떨어지는 좀비 수가 많습니다. 지속시간 동안 계속 쏟아지므로 이동하면서 버티거나, 좁은 통로로 유도하는 편이 낫습니다.

## 떨어지는 좀비 구성

종류별 마릿수를 서버장이 따로 정합니다. 기본은 일반 좀비 95 + 뛰는 좀비 5입니다.

[특수좀비](mutant-spawn.md)를 넣으면 체력·능력·이름표 모두 특수좀비 소환과 같은 설정을 따릅니다.

## 서버 설정

| 옵션 | 범위 | 기본값 | 설명 |
| ---- | ---- | ------ | ---- |
| `Rain_Style` | - | 좀비 레인 | 공습 방식 (좀비 레인 / 좀비 공중투하) |
| `Rain_Radius` | 3~50 | 20 | 낙하 반경 (타일). 좀비 레인은 플레이어 중심, 공중투하는 그림자 중심 |
| `Rain_Duration` | 5~120 | 30 | 첫 좀비부터 마지막 좀비까지 걸리는 시간 (초) |
| `Rain_Parachute` | - | 꺼짐 | 낙하산 연출 |
| `Rain_Count_Normal` | 0~500 | 95 | 일반 좀비 수 |
| `Rain_Count_Sprinter` | 0~500 | 5 | 뛰는 좀비 수 |
| `Rain_Count_Screamer` | 0~500 | 0 | 스크리머 수 |
| `Rain_Count_Brute` | 0~500 | 0 | 브루트 수 |
| `Rain_Count_Roach` | 0~500 | 0 | 로치 수 |
| `Rain_Count_Tracer` | 0~500 | 0 | 트레이서 수 |
| `Rain_ShowRadius` | - | 켜짐 | 낙하 반경 바닥 표시 (좀비 레인 방식만) |
| `Rain_SafeZoneBlock` | - | 켜짐 | 세이프하우스 안이면 나올 때까지 대기 |
| `Delay_zombie_rain` | 0~60 | 3 | 발동 대기시간 (초) |

!!! warning "마릿수 합계는 최대 500"

    전 종류 합계가 500을 넘으면 비율대로 줄여서 떨어뜨립니다. 수를 크게 늘리면 서버 부하가 커지므로 테스트 후 조정하세요.

!!! info "주변 사람도 알 수 있습니다"

    발동 효과음과 낙하 반경 표시는 근처에 있는 다른 플레이어에게도 전달됩니다. 효과음은 발동 지점에서 멀수록 작게 들립니다.

!!! info "진행 중에는 랜덤 텔레포트가 대기합니다"

    좀비 공습은 **발동한 자리를 기준으로** 낙하 지점을 정해두고 지속시간 동안 계속 떨어뜨립니다. 도중에 [랜덤 텔레포트](random-teleport.md)로 멀리 이동하면 남은 좀비가 떨어지지 않습니다.

    그래서 좀비 공습이 끝날 때까지 랜덤 텔레포트 후원은 큐 박스에서 대기합니다. 다른 기능은 정상적으로 발동합니다.

!!! note "이름표 표시 조건"

    뛰는 좀비와 특수좀비의 이름표는 [특수좀비](mutant-spawn.md) 이름표 설정(`Mutant_NameTag`)을 따릅니다.
