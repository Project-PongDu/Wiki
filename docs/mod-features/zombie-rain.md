# 좀비 레인

`zombie_rain` · 개인 후원

플레이어 주변 반경에 좀비가 **하늘에서 떨어집니다.** 지속 시간 동안 계속 낙하하며, 남은 시간이 화면에 카운트다운으로 표시됩니다.

낙하 데미지는 무효화되어 착지 시점의 체력이 원래대로 복구됩니다. 넘어짐 연출만 그대로 남습니다.

## 샌드박스 옵션

| 옵션                     | 범위   | 기본값 | 설명                                     |
| ------------------------ | ------ | ------ | ---------------------------------------- |
| `Rain_Radius`            | 10~50  | 20     | 낙하 반경 (타일)                         |
| `Rain_Duration`          | 5~120  | 30     | 지속 시간 (초)                           |
| `Rain_Count`             | 10~500 | 100    | 총 낙하 마릿수                           |
| `Rain_SprinterPercent`   | 0~100  | 5      | 스프린터 비율 (%)                        |
| `Rain_SprinterNameTag`   | -      | 켜짐   | 스프린터 이름표 표시                     |
| `Rain_ShowRadius`        | -      | 꺼짐   | 낙하 반경을 바닥 마커로 표시             |
| `Rain_SafeZoneBlock`     | -      | 켜짐   | 세이프존 안에서는 벗어날 때까지 대기     |
| `Delay_zombie_rain`      | 0~60   | 3      | 발동 대기시간 (초)                       |

!!! note "이름표 표시 조건"

    스프린터 이름표는 [특수좀비](mutant-spawn.md) 이름표 시스템을 공유합니다. `Mutant_NameTag`가 꺼져 있으면 `Rain_SprinterNameTag`를 켜도 표시되지 않습니다.
