# 특수좀비 소환

`mutant_spawn` · 개인 후원

특수좀비 4종 중 하나를 무작위로 소환합니다. 스크리머·브루트는 CDDA Zombies 모드의 동작 로직만 떼어 자체 이식한 것으로, **CDDA 모드 의존성은 없습니다.**

| 종류                    | 특징                                                                          |
| ----------------------- | ----------------------------------------------------------------------------- |
| 스크리머 (Screamer)     | HP 1, 일반 걸음. 타깃이 생기면 주기적으로 비명을 질러 반경 50 내 좀비를 유인   |
| 브루트 (Brute)          | HP 3, 스프린터, 괴력, 넉다운 면역, 공격 시 플레이어를 밀쳐냄                   |
| 로치 (Roach)            | HP 1, 크롤 전용 + 크롤 속도 3배. 자체 제작 애니메이션                          |
| 트레이서 (Tracer)       | 파쿠르 계열 개체                                                              |

소환된 특수좀비는 머리 위에 종류 이름표가 뜨고, 등장 시 랜덤 조합된 대사를 외칩니다.

## 샌드박스 옵션

| 옵션                  | 기본값 | 설명                                     |
| --------------------- | ------ | ---------------------------------------- |
| `Mutant_NameTag`      | 켜짐   | 특수좀비 이름표 표시                     |
| `Mutant_Screamer`     | 켜짐   | 스크리머를 등장 풀에 포함                |
| `Mutant_Brute`        | 켜짐   | 브루트를 등장 풀에 포함                  |
| `Mutant_Roach`        | 켜짐   | 로치를 등장 풀에 포함                    |
| `Mutant_Tracer`       | 켜짐   | 트레이서를 등장 풀에 포함                |
| `Delay_mutant_spawn`  | 3      | 발동 대기시간 (초)                       |

!!! tip "전부 꺼두면?"

    4종을 모두 해제하면 특수좀비 대신 **일반 스프린터 1마리**가 소환됩니다.

!!! info "부활에도 유지되는 특수좀비"

    특수좀비는 [강령술](rise-up-dead-man.md)로 부활해도 종류와 능력이 그대로 유지됩니다.

!!! warning "세이프존 대기"

    세이프존 안에 있으면 벗어날 때까지 대기했다가 발동합니다.
