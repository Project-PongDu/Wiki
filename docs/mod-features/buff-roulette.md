# 버프 룰렛

`buff_roulette` · 개인 후원

[디버프 룰렛](debuff-roulette.md)과 같은 슬롯머신 연출로, 같은 계열 상태이상을 **반대 방향**으로 적용합니다.

| 후보        | 효과              |
| ----------- | ----------------- |
| 만취 해소   | 취기 -30          |
| 지구력 회복 | 지구력 +0.3       |
| 포만감      | 허기 -0.3 (배부름) |
| 허기 완화   | 허기 -0.3         |
| 패닉 완화   | 패닉 -30          |
| 스트레스 완화 | 스트레스 -0.3    |

디버프 룰렛에 있는 **출혈**만 버프 쪽 후보에서 빠져 있어 6종입니다.

- 세이프존 안에서도 즉시 발동합니다.
- 대기시간: `Delay_buff_roulette` (기본 3초)
