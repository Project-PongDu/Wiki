# 버프 룰렛

`buff_roulette` · 개인 후원

7가지 버프 후보 중 하나가 무작위로 뽑혀 즉시 적용됩니다. 뽑히는 순간 캐릭터가 말풍선으로 결과를 말하고(ding 효과음), 0.5초 뒤 실제 효과가 적용됩니다.

모든 효과의 증감폭은 **해당 스탯 전체 범위의 20%**로 통일되어 있습니다(범위를 벗어나지 않도록 clamp).

| 후보        | 효과                                  |
| ----------- | -------------------------------------- |
| 취함 감소   | 취기 -20 (0~100 기준)                 |
| 지구력 증가 | 지구력 +0.2 (0~1 기준)                |
| 포만감 증가 | 허기/포만감 게이지가 포만 방향으로 20% 이동 |
| 공황 감소   | 공황 -20 (0~100 기준)                 |
| 스트레스 감소 | 스트레스 -0.2 (0~1 기준)            |
| 피곤함 감소 | 피로 -0.2 (0~1 기준)                  |
| 우울함 감소 | 불행 -20 (0~100 기준)                 |

[디버프 룰렛](debuff-roulette.md)과 같은 7종 스탯을 반대 방향으로 다루는 짝 기능입니다.

- 세이프존 안에서도 즉시 발동합니다.
- 대기시간: `Delay_buff_roulette` (기본 3초)
