# 좀비 룰렛

`zombie_roulette` · 개인 후원

룰렛 연출 후 결과가 확정되면 좀비가 스폰됩니다. 스폰 수량은 룰렛 결과에 따라 무작위로 정해집니다.

| 샌드박스 옵션           | 범위 | 기본값 | 설명               |
| ----------------------- | ---- | ------ | ------------------ |
| `Roulette_MinCount`     | 1~20 | 2      | 최소 소환 마릿수   |
| `Roulette_MaxCount`     | 1~30 | 6      | 최대 소환 마릿수   |
| `Delay_zombie_roulette` | 0~60 | 3      | 발동 대기시간 (초) |

!!! warning "세이프존 대기"

    세이프존 안에 있으면 벗어날 때까지 대기했다가 발동합니다.
