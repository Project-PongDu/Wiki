# 호드나이트

`horde_night` · **서버 후원**

**서버장에게** 후원이 들어오면 그날 밤에 대규모 좀비 떼가 몰려옵니다. 원본 Horde Night 모드의 인게임 스펙을 이식하되, 발동 트리거를 날짜 주기가 아니라 **후원 예약**으로 바꾼 버전입니다.

## 예약 모델

후원 1건 = 예약 1건입니다.

| 상황                 | 발동 시점                        |
| -------------------- | -------------------------------- |
| 발동 시각 이전 후원  | 그날 밤                          |
| 발동 시각 이후 후원  | 다음날 밤                        |
| 중복 후원            | 하루 1건씩 소모되어 연달아 발동  |

예약은 서버 데이터에 저장되므로 **서버를 재시작해도 유지**됩니다.

후원이 접수되면 접속자 전원이 예고 심박음과 함께 대사를 외칩니다. 발동 시각이 되면 다시 경고 대사가 나오고, 세션이 끝나면 종료 대사가 나옵니다.

## 인디케이터

예약이 걸려 있거나 스폰이 진행 중이면, 화면 우측 무들(상태 아이콘) 스택 **최상단**에 호드나이트 아이콘이 표시됩니다. 마우스를 올리면 시작/종료까지 남은 시간이 나오고, 예약이 2건 이상이면 개수가 겹쳐 표시됩니다.

## 스폰 방식

접속자 **전원** 각자의 주변에 독립 세션이 열립니다. 지정한 지속 시간 동안 지정 마릿수를 균등한 간격으로 스폰합니다. 간격은 현실 시간이 아니라 **인게임 시간** 기준이므로, 낮 길이 설정이나 배속 모드에 자동으로 따라갑니다.

!!! warning "이 기능은 좀비를 유인합니다"

    퐁듀의 다른 기능들은 좀비 어그로가 붙지 않도록 월드 사운드를 쓰지 않지만, 호드나이트는 **예외**입니다. 원본 호드나이트의 실질 메커니즘이 스폰 마릿수가 아니라 유인 사운드이기 때문입니다.

    반경 200의 유인 사운드는 맵 밖 가상 좀비 인구까지 소리 쪽으로 이주시킵니다. 즉 스폰되는 좀비는 씨앗일 뿐이고, 실제 호드 규모는 이 이주가 만듭니다.

## 샌드박스 옵션

| 옵션                   | 범위    | 기본값 | 설명                              |
| ---------------------- | ------- | ------ | --------------------------------- |
| `Horde_Hour`           | 0~23    | 22     | 발동 시각 (인게임 시)             |
| `Horde_Count`          | 1~500   | 200    | 세션당 스폰 마릿수                |
| `Horde_DurationMin`    | 10~1440 | 120    | 지속 시간 (인게임 분)             |
| `Horde_Distance`       | 10~90   | 55     | 스폰 거리 (타일)                  |
| `Horde_ShowIndicator`  | -       | 켜짐   | 무들 인디케이터 표시              |
| `Delay_horde_night`    | 0~60    | 3      | 발동 대기시간 (초)                |

!!! warning "서버장 판정"

    [의약품 랜덤박스](medical-box.md)와 동일하게 `Host_SteamID` 기준으로 서버가 판정합니다.
