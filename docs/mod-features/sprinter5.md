# 뛰좀 소환

`sprinter5` · 개인 후원

연출 없이 **뛰는 좀비(스프린터)** 를 곧바로 스폰 큐에 등록합니다. [좀비 룰렛](zombie-roulette.md)과 달리 랜덤 범위가 아니라 설정한 수만큼 정확히 소환됩니다.

| 샌드박스 옵션      | 범위 | 기본값 | 설명               |
| ------------------ | ---- | ------ | ------------------ |
| `Sprinter_Count`   | 1~10 | 2      | 소환 마릿수        |
| `Delay_sprinter5`  | 0~60 | 3      | 발동 대기시간 (초) |

!!! warning "세이프존 대기"

    세이프존 안에 있으면 벗어날 때까지 대기했다가 발동합니다.
