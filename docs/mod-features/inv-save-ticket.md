# 인벤토리 세이브 티켓

`inv_save_ticket` · 개인 후원

티켓을 소지한 상태로 사망하면(좀비화 포함) 티켓 1장을 소모하고, **사망 시점의 인벤토리 전체**를 리스폰 후 그대로 돌려받습니다.

## 동작

1. 사망 시점에 인벤토리 전체를 스냅샷으로 저장하고, 캐릭터 인벤토리를 비웁니다.
2. 시체/좀비에는 **아무것도 남지 않습니다.** (이중 지급 원천 차단)
3. 리스폰 3초 후 스냅샷을 복원합니다. 입고 있던 옷은 같은 부위에 다시 입혀지고, 손에 쥐고 있던 무기는 같은 손에 재장착됩니다.

사망 직전에 피격으로 흘린 손 무기도, 아무도 줍지 않았다면 회수 대상에 포함됩니다.

스냅샷은 클라이언트 로컬 파일에 저장되므로 **사망~리스폰 사이에 게임이 튕겨도** 재접속 후 정상 복원됩니다.

## 보존되는 상태

커스텀 이름 / 내구도 / 소모품 잔량 / 총기(장전 수, 약실, 탄창 삽입, 부착물) / 독립 탄창 잔탄 / 음식(부패도, 섭취 잔량) / 의류(오염, 피, 젖음) / 외형(색상, 텍스처, 데칼) / 열쇠 / 가방 중첩 구조 전체 / 손 장착 / 핫바 부착 슬롯

## 복원되지 않는 것

라디오류 기기 설정, 의류 구멍·패치 상태, 지도 필기, 일부 동적 표시 상태.

의류의 이름은 일부러 복원하지 않습니다 — 게임이 "더러움/해짐/젖음" 접두어를 매번 새로 계산해 붙이기 때문에, 이름을 그대로 복원하면 부활할 때마다 접두어가 누적됩니다. 오염도·내구도·젖음만 복원하면 게임이 알아서 정확히 다시 계산합니다.

- 세이프존 안에서도 즉시 지급됩니다.
- 대기시간: `Delay_inv_save_ticket` (기본 3초)
