# 릴리즈 노트

사용자가 체감하는 변경사항 위주로 정리합니다.

## 퐁듀 런처

### v5.4.0 <small>2026-08-17</small>

- 메인 화면의 리워드 티어 목록이 **실시간으로 갱신**됩니다. 서버장이 방송 중에 금액을 바꿔도 런처를 껐다 켤 필요가 없습니다.
- 테스트 후원 목록도 함께 갱신됩니다.

### v5.3.4 <small>2026-08-17</small>

- 게임 최적화가 테스트 모드에서 사용할 수 없던 문제 수정.

### v5.3.1 <small>2026-08-17</small>

- **게임 최적화 창을 새로 만들었습니다.** 자동 적용이 사라지고, 원하는 항목만 골라 적용/해제하는 방식이 되었습니다.
- 게이트 화면 정리.

### v5.1.1 <small>2026-08-13</small>

- **블러드문** 리워드 추가.

### v5.0.1 <small>2026-08-11</small>

- **후원 금액을 서버장이 정하도록 변경되었습니다.** 런처의 금액 편집 기능이 사라지고, 접속한 서버의 설정을 그대로 표시합니다.
- 준비 확인에 **"서버 리워드 설정 확인"** 항목 추가.
- **Zomboid 폴더를 한 번만 지정**하면 되도록 변경. 자동 탐지가 빗나갔을 때 한 곳만 고치면 전부 해결됩니다.

### v4.3.1 <small>2026-08-06</small>

- **의약품 랜덤박스** 서버 후원 추가.

### v4.2.4 <small>2026-08-04</small>

- 리워드 티어 목록 화면 개선.

### v4.1.1 <small>2026-08-02</small>

- "혈청" 명칭을 "각성제"로 변경.

### v4.0.0 <small>2026-07-22</small>

- **치지직 공식 API로 전환.** 로그인 방식이 바뀌었습니다.
- 채널 주소·이름 입력이 사라지고, **로그인한 계정의 채널이 곧 연동 대상**이 됩니다.
- 한 번 로그인하면 다음 실행부터 자동 로그인됩니다.
- **19세 방송 제한이 없어졌습니다.**

## 퐁듀 모드

### 2026-08-22

- **강령술이 세이프하우스 안에서는 대기**하도록 변경. 밖으로 나올 때까지 발동하지 않습니다. (좀비 룰렛·뛰좀·특수좀비와 같은 정책)
- **랜덤 텔레포트 도착 지점에서 세이프하우스가 제외**됩니다. 남의 거점 한가운데에 떨어지지 않습니다.
- **좀비 레인 / 화력지원이 진행 중이면 랜덤 텔레포트가 대기**합니다. 도중에 멀리 이동하면서 남은 효과가 사라지던 문제 해결.

### 2026-08-17

- 좀비 랜덤화 모드(BLT)를 함께 쓸 때, 소환된 특수좀비가 잠시 뒤 일반 좀비처럼 느려지고 능력을 잃던 문제 수정.
- 서버 설정 화면 구분선 정리.

### 2026-08-15

- 서버장이 방송 중에 금액을 바꾸면 스트리머들의 런처에 즉시 반영되도록 개선.

### 2026-08-13

- 블러드문 연출 마무리 (조명·화면 효과·사운드).
- 서버 설정 탭 정렬 순서 변경, 번역 정리.
- 의약품 랜덤박스 아이콘 추가.

### 2026-08-12

- **블러드문** 서버 후원 추가 — 일정 시간 좀비 전원 가속 + 핏빛 조명. 중복 후원은 시간이 연장됩니다.
- 블러드문 인디케이터, 시작·연장·종료 대사 및 효과음 추가.

### 2026-08-11

- **후원 금액 설정이 서버 설정(퐁듀 - 메인 탭)으로 이전되었습니다.**
- 의약품 랜덤박스에 **좀복시비르 앰퓰** 추가 (4종 → 5종).
- 좀비 랜덤화 모드 호환 패치.

### 2026-08-09

- 버프/디버프 룰렛 효과 크기 조정.
- 배고픔 관련 버그 수정.

### 2026-08-06

- **의약품 랜덤박스** 서버 후원 추가.
- 폭격 반경 안의 **차량이 고철이 되도록** 변경.
- 폭격 시 좀비화된 플레이어 시체에서 아이템이 사라지던 문제 수정.
- 호드나이트 인디케이터를 상태 아이콘 방식으로 변경.
- 우클릭 메뉴 개편.

### 2026-08-05

- 차량 운전 중 랜덤 텔레포트 시 대시보드가 남던 문제 수정.
- 미사용 기능(산타마을 유배 / 백룸) 제거.

### 2026-08-04

- 서버 설정 기본값 밸런스 조정.

- 헬기 화력지원 사운드가 사격 종료 후에도 계속 재생되던 문제 수정.

### 2026-08-03

- **호드나이트** 서버 후원 추가.
- 랜덤 텔레포트 복귀 타이머 진행 중 연속 발동 차단.
- 사운드 볼륨 전반 조정.
