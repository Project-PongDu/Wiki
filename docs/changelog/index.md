# 릴리즈 노트

사용자가 체감하는 변경사항 위주로 정리합니다.

## 퐁듀 런처

### v5.8.3 <small>2026-09-18</small>

- "좀비 레인" 표시명을 **"좀비 공습"** 으로 변경.

### v5.8.2 <small>2026-09-15</small>

- 업데이트 창 진행바를 런처 테마에 맞게 변경.

### v5.8.1 <small>2026-09-15</small>

- 업데이트 후 자동 재시작 시 "no Qt platform plugin" 오류 창이 뜨던 문제 수정. (v5.8.0 → v5.8.1 업데이트 때는 한 번 더 뜰 수 있습니다)

### v5.8.0 <small>2026-09-15</small>

- 서버에 설치된 **애드온 모드의 후원 기능**을 리워드 티어 목록에 표시.

### v5.7.0 <small>2026-08-27</small>

- **즉시 치유**, **랜덤 부상** 리워드 추가.

### v5.6.2 <small>2026-08-25</small>

- 런처의 백그라운드 자원 사용량 감소, 로그가 너무 길어지지 않도록 정리.

### v5.4.3 <small>2026-08-24</small>

### v5.4.1 <small>2026-08-18</small>

- 리워드 티어 목록에서 서버 후원을 아래쪽에 정렬.

### v5.4.0 <small>2026-08-17</small>

### v5.3.4 <small>2026-08-17</small>

- 준비 확인에 **"서버 리워드 설정 확인"** 항목 추가.
- **Zomboid 폴더를 한 번만 지정**하면 되도록 변경. 자동 탐지가 빗나갔을 때 한 곳만 고치면 전부 해결됩니다.

- **19세 방송 제한이 없어졌습니다.**

## 퐁듀 모드

### 2026-09-22

- **강령술 연출 방식 추가** — 기존 보라색 원 대신 **재활성화 가스 살포**(바닥에 보라색 가스가 퍼졌다 걷힘)를 고를 수 있습니다. 연출만 바뀌고 부활 동작은 같습니다.
- 화면 카운터 표기 통일 (기능 이름 + 남은 시간).
- 헬기 화력지원 중 소리와 사격은 나오는데 헬기 기체가 보이지 않던 문제 수정.
- GunFighter 모드와 함께 쓸 때 좀비화된 플레이어를 때리면 오류가 나던 문제 수정.

### 2026-09-20

- **헬기·드론 화력지원이 크리티컬/일반 데미지 방식으로 변경.** 즉사 아니면 무피해였던 방식에서, 한 발마다 크리티컬 또는 일반 데미지가 들어가는 방식이 되었습니다. 관련 설정이 바뀌었습니다. ([화력지원 룰렛](../mod-features/fire-support.md))
- 헬기·드론 조준 정확도 개선 — 이미 죽은 좀비를 계속 쏘거나, 넘어진 좀비만 붙잡고 있던 문제 해결.
- 드론 공전 반경·주기 설정 제거 (고정값).
- 기본값 조정 — 헬기 약 100마리, 드론 약 50마리 처치 수준.

### 2026-09-18

- **좀비 레인 → 좀비 공습으로 개편.** ([좀비 공습](../mod-features/zombie-rain.md))
    - 공습 방식 선택 — **좀비 레인**(기존) / **좀비 공중투하**(수송기 그림자가 지나가며 투하).
    - **낙하산 연출** 옵션 추가.
    - 종류별 마릿수 설정 — 일반·뛰는 좀비·스크리머·브루트·로치·트레이서를 각각 지정.
    - 7층 높이에서 낙하, 착지 피해 없음, 낙하 중 자세 고정.
- 화면 카운터가 FPS에 따라 빠르거나 느리게 흐르던 문제 수정. 이제 실제 시간 기준입니다.
- 서버 설정 설명 문구 간결화, "밴딧" 표기를 "히트맨"으로 통일.
