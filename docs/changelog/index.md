# 릴리즈 노트

주요 변경사항만 정리합니다. 사소한 수정과 내부 리팩터링은 생략했습니다.

## 퐁듀 런처

### v5.4.0 <small>2026-08-17</small>

- 메인 화면 리워드 티어가 **실시간 갱신**됩니다. 서버장이 게임 안에서 샌드박스 값을 바꾸고 Apply를 누르면 런처를 재시작하지 않아도 3초 안에 목록이 따라갑니다.
- 테스트 후원 드롭다운도 함께 갱신됩니다. 고르고 있던 금액이 새 목록에 남아 있으면 선택 상태를 유지합니다.

### v5.2.x ~ v5.3.x <small>2026-08-17</small>

- **게임 최적화 창을 새로 만들었습니다.** 자동 적용이 사라지고, 항목별 체크박스로 직접 골라 적용/해제하는 방식이 되었습니다. 항목은 5개 그룹(청크 로딩 / 월드 업데이트 / 좀비 네트워크 패킷 / 좀비 개체수 / JVM 힙)입니다.
- 게임 최적화가 테스트 모드에서 항상 차단되던 문제 수정.
- 게이트 UI 정리.

### v5.1.1 <small>2026-08-13</small>

- **블러드문** 리워드 추가.

### v5.0.x <small>2026-08-11</small>

- **리워드 티어 소유권이 모드로 이전되었습니다.** 금액↔기능 매핑을 서버 샌드박스가 소유하고, 런처는 모드가 게시한 `pongdu_tiers.txt`를 읽어 표시만 합니다. 런처의 티어 편집 UI와 프리셋 잠금 기능은 삭제되었습니다.
- 게이트 체크리스트에 **"서버 리워드 설정 확인"** 항목 추가.
- **Zomboid 폴더를 한 번만 지정**하면 `rewards.txt` / `pz_status.txt` / `pongdu_tiers.txt` 경로가 전부 거기서 파생됩니다. 파일별로 따로 탐지하던 방식을 폐지했습니다.

### v4.3.1 <small>2026-08-06</small>

- **의약품 랜덤박스** 서버 후원 추가.

### v4.2.4 <small>2026-08-04</small>

- 리워드 티어표 UI 개선.

### v4.1.1 <small>2026-08-02</small>

- "혈청" 명칭을 "각성제"로 변경.

### v4.0.0 <small>2026-07-22</small>

- **치지직 공식 Open API로 전환.** 비공식 채팅 WebSocket 방식을 폐기하고 OAuth2 로그인 + 공식 세션 구독으로 바뀌었습니다.
- 채널 URL·이름 직접 입력이 사라지고, **로그인한 계정의 채널이 곧 연동 대상**이 됩니다.
- Client Secret이 런처에서 제거되고 퐁듀 인증 서버(Cloudflare Workers)로 이동. 화이트리스트 검사도 인증 서버가 담당합니다.
- **19세 방송 차단과 NID 쿠키 입력이 제거되었습니다.** 공식 API는 성인방송 여부와 무관하게 후원을 전달합니다.
- Refresh Token 저장으로 재실행 시 무브라우저 자동 로그인.

## 퐁듀 모드

### 2026-08 중순

- **블러드문**(`blood_moon`) 서버 후원 추가 — 좀비 전원 스프린터화 + 핏빛 조명 + 화면 틴트 + 하울링 연출. 중복 후원은 재시작이 아니라 연장으로 처리됩니다.
- **리워드 티어 샌드박스 이전** — `PongDu.Tier_<featureId>` 옵션 신설, 접속 시 및 관리자 Apply 시 `pongdu_tiers.txt` 게시.
- 샌드박스 **퐁듀 - 메인** 탭 신설, 탭 정렬 순서 변경.
- 의약품 랜덤박스 추첨 풀에 **좀복시비르 앰퓰** 추가 (4종 → 5종).
- 좀비 랜덤화 모드 호환 패치.

### 2026-08 초순

- **의약품 랜덤박스**(`medical_box`) 서버 후원 추가. 주사기 4종(전투자극제 / 범용 치유제 / 급성 진통제 / 응급 지혈제) 신설.
- 폭격 세이프존 대기 옵션(`Bombard_SafeZoneBlock`) 추가.
- 폭격 반경 내 **차량 고철화**(`Bombard_VehicleDamage`) 추가.
- 폭격 시 좀비화된 플레이어 시체에서 아이템이 사라지던 문제 수정.
- 차량 탑승 중 랜덤 텔레포트 시 무한 버벅임 문제 수정.
- 호드나이트 인디케이터를 무들 방식으로 변경.
- 우클릭 컨텍스트 메뉴 개편.
- 미사용 기능(산타마을 유배 / 백룸) 정리.
