## ✨ 주요 특징

- 치지직 후원 실시간 연동
- Project Zomboid 전용
- 개인 후원 / 서버 후원 분리 — 스트리머 한 명에게만 적용되는 기능과 서버 전체에 적용되는 기능
- 후원 금액부터 기능별 세부 수치까지 서버 설정에서 조정 가능
- 직관적인 설정 UI

## 🧩 구성 요소

| 이름          | 역할                                                    |
| ------------- | ------------------------------------------------------- |
| **퐁듀 런처** | 치지직 후원을 감지해 게임으로 전달하는 데스크톱 앱      |
| **퐁듀 모드** | 전달받은 후원을 인게임 효과로 실행하는 좀보이드 모드    |
| **퐁듀 위키** | 이 문서                                                 |

시스템 전체를 가리킬 때는 그냥 **퐁듀**라고 부릅니다.
