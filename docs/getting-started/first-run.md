# 최초 실행

`PongDu.exe`를 실행하면 나오는 게이트 화면(런처)의 흐름을 순서대로 설명합니다.

!!! note "중복 실행 방지"

    이미 퐁듀가 실행 중인 상태에서 한 번 더 실행하면 "이미 실행 중입니다" 경고가 뜨고 종료됩니다. 실행파일 여러 개를 동시에 띄울 수 없습니다.

## 1단계 — 치지직 로그인

첫 화면에서 **치지직 로그인** 버튼을 누르면 브라우저가 열립니다. 치지직 계정으로 로그인하면 자동으로 런처로 돌아오며, 로그인한 계정의 채널이 그대로 연동 대상이 됩니다 (별도로 채널 URL이나 이름을 입력하지 않습니다).

이전에 로그인한 적이 있으면 브라우저를 띄우지 않고 저장된 로그인 정보로 조용히 자동 로그인을 시도합니다. 자동 로그인이 실패하면 로그인 버튼이 다시 나타납니다.

로그인에 성공하면 서버가 이번 시즌 화이트리스트에 등재되어 있는지 확인합니다.

!!! failure "시즌 참가 목록에 없는 채널입니다"

    로그인한 계정의 채널이 화이트리스트에 없으면 이 오류가 뜹니다. 로그인 자체는 유효하므로, **다른 계정으로 로그인** 버튼으로 다른 계정을 시도할 수 있습니다.

## 2단계 — 연동 체크리스트

로그인에 성공하면 아래 4가지 항목을 3초 간격으로 자동 갱신하며 보여줍니다. 모두 초록색이 되어야 다음으로 넘어갈 수 있습니다.

| 항목             | 의미                                 |
| ---------------- | ------------------------------------ |
| 치지직 로그인 완료 | 1단계에서 이미 통과됨                |
| 생방송 중        | 현재 방송이 켜져 있는지              |
| PZ 실행 중       | Project Zomboid 프로세스가 떠 있는지 |
| 인게임 접속 완료 | PZ 서버에 실제로 접속해 있는지       |

이 화면에서 **리워드 프리셋 편집하기** 버튼으로 후원 금액별 기능 매핑을 미리 편집·저장해둘 수도 있습니다.

모든 체크리스트가 통과되면 **연동 시작** 버튼이 활성화되고, 클릭 시 실제 연동 화면(메인 창)으로 넘어갑니다.

## PZ 원클릭 최적화 (자동)

런처 창이 뜨고 약 0.4초 뒤, 별도의 확인창 없이 PZ 최적화가 자동으로 시도됩니다.

- **최초 실행**: 강제로 최적화를 적용하고 이후에도 자동 유지되도록 설정을 저장합니다.
- **이후 실행**: 게임 업데이트 등으로 패치 상태가 어긋나 있으면 조용히 다시 적용합니다.
- **사용자가 직접 "해제"를 누른 경우**: 그 상태를 기억하고 자동으로 다시 적용하지 않습니다.

!!! tip "PZ 실행 중이면 적용 안 됨"

    게임이 이미 켜져 있으면 최적화를 적용할 수 없습니다. 화면 하단에 "게임 최적화 대기" 문구가 뜨면 게임을 끈 뒤 퐁듀를 재시작하세요.

화면 하단의 상태 문구로 현재 최적화 여부를 확인할 수 있고, 옆의 **적용 / 해제** 버튼으로 언제든 전환할 수 있습니다.
