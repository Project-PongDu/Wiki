# 최초 실행

`PongDu.exe`를 실행하면 나오는 게이트 화면(런처)의 흐름을 순서대로 설명합니다.

!!! note "중복 실행 방지"

    이미 퐁듀가 실행 중인 상태에서 한 번 더 실행하면 "이미 실행 중입니다" 경고가 뜨고 종료됩니다. 실행파일 여러 개를 동시에 띄울 수 없습니다.

## 1단계 — 치지직 로그인

첫 화면에서 **치지직 로그인** 버튼을 누르면 브라우저가 열립니다. 치지직 계정으로 로그인하면 자동으로 런처로 돌아오며, 로그인한 계정의 채널이 그대로 연동 대상이 됩니다 (별도로 채널 URL이나 이름을 입력하지 않습니다).

이전에 로그인한 적이 있으면 브라우저를 띄우지 않고 저장된 로그인 정보로 조용히 자동 로그인을 시도합니다. 자동 로그인이 실패하면 로그인 버튼이 다시 나타납니다.

로그인에 성공하면 서버가 이번 시즌 화이트리스트에 등재되어 있는지 확인합니다.

!!! failure "시즌 참가 목록에 없는 채널입니다"

    로그인한 계정의 채널이 화이트리스트에 없으면 이 오류가 뜹니다. 로그인 자체는 유효하므로, **다른 계정으로 로그인** 버튼으로 다른 계정을 시도할 수 있습니다.

## 2단계 — 연동 준비 확인

로그인에 성공하면 아래 4가지 항목을 3초 간격으로 자동 갱신하며 보여줍니다. 모두 초록색이 되어야 **연동 시작** 버튼이 활성화됩니다.

| 항목 | 의미 |
| ---- | ---- |
| 치지직 로그인 완료 | 1단계에서 이미 통과됨 (로그인 + 화이트리스트) |
| 생방송 중 | 현재 방송이 켜져 있는지 |
| 인게임 접속 완료 | Project Zomboid 서버에 실제로 접속해 있는지 |
| 서버 리워드 설정 확인됨 | 접속한 서버의 [리워드 티어](../pongdu-launcher/reward-tiers.md)를 읽어왔는지 |

마지막 항목은 인게임 접속이 확인된 뒤에만 판정합니다. 접속 전에는 "인게임 접속 후 확인됩니다"로 표시되고, 접속이 끊기면 다시 미확인 상태로 돌아갑니다.

## Zomboid 폴더 지정

체크리스트 아래에 **Zomboid 폴더** 입력칸이 있습니다. 퐁듀가 모드와 주고받는 파일 3종이 전부 이 폴더의 `Lua/` 하위에 있습니다.

| 파일 | 방향 | 용도 |
| ---- | ---- | ---- |
| `pz_status.txt` | 모드 → 런처 | 인게임 접속 상태 |
| `pongdu_tiers.txt` | 모드 → 런처 | 서버 리워드 티어 |
| `rewards.txt` | 런처 → 모드 | 후원 이벤트 |

보통은 자동 탐지된 값이 그대로 맞습니다. 자동 탐지가 틀렸다면 **폴더 선택**으로 한 번만 바로잡으면 세 파일이 전부 같이 해결됩니다.

## 게임 최적화 (선택)

로그인 화면 하단의 **게임 최적화** 버튼으로 별도 설정 창을 엽니다. **자동으로 적용되는 것은 없고**, 창에서 항목을 골라 **적용**을 눌렀을 때만 게임 파일이 바뀝니다. 자세한 내용은 [PZ 게임 최적화](../pongdu-launcher/pz-optimization.md) 참고.

!!! tip "PZ 실행 중이면 적용 안 됨"

    게임이 켜져 있으면 파일을 교체할 수 없습니다. 게임을 끈 뒤에 적용하세요.

## 3단계 — 메인 창

**연동 시작**을 누르면 메인 창으로 넘어가고, 창이 뜬 직후 자동으로 연동이 시작됩니다. 여기서 서버 리워드 티어 목록, 테스트 후원, 실시간 후원 로그를 확인할 수 있습니다.

연동을 중지하거나 PZ 종료·인게임 이탈이 감지되면 자동으로 게이트 화면으로 돌아갑니다.
